# 1526. 形成目标数组的子数组最少增加次数

- 难度：困难
- 标签：栈、贪心、数组、前缀和
- 链接：https://leetcode.cn/problems/minimum-number-of-increments-on-subarrays-to-form-target-array/
- 所属：家族 3：前缀和与哈希计数

---

给你整数数组 target 和初始全 0 的同长数组 arr。一次操作可选 arr 的任意连续子数组，将其每个元素加 1。返回使 arr 变为 target 的最少操作次数。

**示例 1：**
```
输入：target = [1,2,3,2,1]
输出：3
解释：对 [0,4] 加 1、对 [1,3] 加 1、对 [2,2] 加 1。
```
**示例 2：**
```
输入：target = [3,1,1,2]
输出：4
```
**提示：**

- 1 <= target.length <= 10^5
- 1 <= target[i] <= 10^5
