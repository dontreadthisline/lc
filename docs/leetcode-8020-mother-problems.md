# LeetCode 二八纲：算法思维母题库与针对性训练

> **本文是方法论层**：为什么这么分类、怎么练、过关标准是什么。
> **进度与题目的唯一事实源**：`mother-problems/INDEX.md`（127 道题、18 个家族、逐题状态与思路列）。两者不重复：题目清单只在 INDEX 维护，本文只讲"为什么"和"怎么练"。

## 0. 二八切法的实测证据

- 官方 170 个标签中，**9 个 P0 思维标签**（哈希表/双指针/滑动窗口/二分查找/DFS/BFS/回溯/DP/贪心，占标签总量的 5%）覆盖 **69.1%** 的算法题
- 扩展到 **20 个核心思维标签**（占标签总量的 12%），覆盖 **80.8%** 的算法题
- 本材料 **127 道母题 ≈ 算法题总量的 3.2%**，用于生成这 80% 考法

结论：刷题不是在 3916 里采样，是在十几个思维里循环。题是载体，思维是目的。

## 1. 母题方法论

**母题的定义**：一族题的生成元。掌握母题后，族内变体只是"识别信号 + 参数调整"，不需要新知识。

**三遍法（每道母题）**：
1. 第一遍：25 分钟无提示。想不出来才看题解，看完关掉题解**凭记忆重写**，写不通说明没懂
2. 第二遍：3 天后重做，目标 10 分钟内一次通过
3. 第三遍：7 天后口述：什么信号让你想到这个解？为什么它是对的（不变式/交换论证）？变体往哪个方向改会破坏解？

**错题本必记三字段**：识别信号（题面哪里暗示了这个思维）/ 关键转折（卡住的那一步）/ 破坏性变体（怎么改题就没法这么做了）。

**过关标准（全库统一）**：每道母题做到"白板一次通过 + 说出识别信号 + 说出正确性论证"，才允许进下一族。

## 2. 元技能：拿到题先反推复杂度（比会做更重要）

| n 的规模 | 可接受复杂度 | 对应思维 |
|---|---|---|
| ≤ 12 | O(n!·n) / O(2^n·n^2) | 回溯全排、状压 |
| ≤ 30 | O(2^n) 带剪枝/折半 | 回溯、meet in the middle |
| ≤ 100 | O(n^3) | 区间 DP、Floyd |
| ≤ 1000（或 O(n^2)=1e6） | O(n^2) | 二维 DP、枚举对 |
| ≤ 1e5 | O(n log n) | 排序、堆、二分、单调栈 |
| ≥ 1e6 | O(n) | 双指针、哈希、前缀和、DP |
| ≥ 1e9 | O(log n) / O(1) | 二分答案、数学、贪心 |

**题面信号 → 思维映射**（错题本"识别信号"栏就按这个归档）：

| 题面特征 | 优先想 |
|---|---|
| 有序数组/答案有单调性（"最小化最大值"） | 二分 / 二分答案 |
| 连续子数组 + 和/个数 | 前缀和 + 哈希（定长→滑窗） |
| 最长/最短无重复、窗口可伸缩 | 滑动窗口 |
| 第 K 大/最频繁/流中位数 | 堆（→已有 heap 题单） |
| 所有排列/组合/子集/棋盘路径 | 回溯 |
| 无权图最短步数/同时扩散 | BFS / 多源 BFS |
| 依赖关系/先修课程 | 拓扑排序 |
| 连通/分组/动态加边 | 并查集 |
| 区间重叠/不重叠最多/区间批量加减 | 排序 + 贪心 / 差分 |
| 方案数/最少代价/能否达成 | DP |
| 两个字符串的公共结构 | LCS 族 / 编辑距离族 |
| 括号 | 有效→栈，生成→回溯，最长→DP |
| 数据流/动态极值 | 堆 / 有序集合 |
| 要求 O(1) 插删取 | 哈希 + 数组交换位（380 型） |
| 只出现一次/其他出现两次 | 异或 |

## 4. 本仓库刷题动线（与 INDEX 配套）

```
读题面 mother-problems/<题号>-<标题>.md
  → lc/<题号>.go 写实现（导出函数名）
  → lc_tests/<题号>_test.go：表驱动用例 + 暴力对拍（2 万组随机）
  → 测试绿 → INDEX 打钩、填思路列
```

**对拍方法论（本仓库核心纪律）**：任何实现配一个 O(n²) 暴力参照，随机数据交叉验证。实战记录：对拍先后抓出过实现侧的三次同型收缩边界 bug、两次区间开闭错位、一次扫描起点错位，也抓出过测试侧的三次期望值/生成器错误——**双向无免检**。

**配套沉淀**：滑窗两流派模板（`lc/sliding_window_template.go`）、差分数学的转化定理（`docs/diff-array-math.md`）、堆与快选的正确性证明（`docs/heap-properties-proof.md`、`docs/quickselect-partition-proof.md`）。

## 6. Go 特化建议

- 每个思维留一个**手写模板文件**（如 `lc/sliding_window_template.go` 已建）：母题调用自己模板而非现场重推
- 堆继续用 `algo/genericheap.go` 的 `NewHeap(func(a,b T) bool)`，215/347 强制不用 `sort.Slice`
- 链表题禁用切片辅助（206/143/25 必须纯指针）
- 排序题 912 手写快排 + 归并，配 `docs/quickselect-partition-proof.md` 理解划分正确性
- 区间判断写法纪律：区间语义写成注释（`// birth <= i < death`）再机械展开为 `&&`，两侧对齐注释
