## 1. 母题方法论

**母题的定义**：一族题的生成元。掌握母题后，族内变体只是"识别信号 + 参数调整"，不需要新知识。

**三遍法（每道母题）**：
1. 第一遍：25 分钟无提示。想不出来才看题解，看完关掉题解**凭记忆重写**，写不通说明没懂
2. 第二遍：3 天后重做，目标 10 分钟内一次通过
3. 第三遍：7 天后口述：什么信号让你想到这个解？为什么它是对的（不变式/交换论证）？变体往哪个方向改会破坏解？

**错题本必记三字段**：识别信号（题面哪里暗示了这个思维）/ 关键转折（卡住的那一步）/ 破坏性变体（怎么改题就没法这么做了）。

**过关标准（全库统一）**：每道母题做到"白板一次通过 + 说出识别信号 + 说出正确性论证"，才允许进下一族。

## 2. 元技能：拿到题先反推复杂度（比会做更重要）

| n 的规模 | 可接受复杂度 | 对应思维 |
|---|---|---|
| ≤ 12 | O(n!·n) / O(2^n·n^2) | 回溯全排、状压 |
| ≤ 30 | O(2^n) 带剪枝/折半 | 回溯、meet in the middle |
| ≤ 100 | O(n^3) | 区间 DP、Floyd |
| ≤ 1000（或 O(n^2)=1e6） | O(n^2) | 二维 DP、枚举对 |
| ≤ 1e5 | O(n log n) | 排序、堆、二分、单调栈 |
| ≥ 1e6 | O(n) | 双指针、哈希、前缀和、DP |
| ≥ 1e9 | O(log n) / O(1) | 二分答案、数学、贪心 |

**题面信号 → 思维映射**（错题本"识别信号"栏就按这个归档）：

| 题面特征 | 优先想 |
|---|---|
| 有序数组/答案有单调性（"最小化最大值"） | 二分 / 二分答案 |
| 连续子数组 + 和/个数 | 前缀和 + 哈希（定长→滑窗） |
| 最长/最短无重复、窗口可伸缩 | 滑动窗口 |
| 第 K 大/最频繁/流中位数 | 堆（→已有 heap 题单） |
| 所有排列/组合/子集/棋盘路径 | 回溯 |
| 无权图最短步数/同时扩散 | BFS / 多源 BFS |
| 依赖关系/先修课程 | 拓扑排序 |
| 连通/分组/动态加边 | 并查集 |
| 区间重叠/不重叠最多 | 排序 + 贪心 |
| 方案数/最少代价/能否达成 | DP |
| 两个字符串的公共结构 | LCS 族 / 编辑距离族 |
| 括号 | 有效→栈，生成→回溯，最长→DP |
| 数据流/动态极值 | 堆 / 有序集合 |
| 要求 O(1) 插删取 | 哈希 + 数组交换位（380 型） |
| 只出现一次/其他出现两次 | 异或 |

## 3. P0：六大母题思维（先吃透，占 69.1% 覆盖）

### 思维 1：空间换时间（哈希）—— 哈希表 870 题

- **核心**：用 O(n) 空间把"查找/计数"从 O(n) 降到 O(1)。一切"两数关系""频次""分组"的地基
- **母题**：1 两数之和(简单) → 49 字母异位词分组(中等) → 128 最长连续序列(中等)
- **族谱信号**：找配对 → 1；按"签名"分组 → 49；集合连续性 → 128（哈希 + 只从序列起点走，O(n) 的关键转折）
- **训练**：128 必须口头证明为什么每个元素只访问两遍仍是 O(n)；217 存在重复元素(简单)当热身
- **过关**：49 的分组键设计（排序串 vs 计数串）能说出两种取舍

### 思维 2：双指针与滑动窗口 —— 双指针 280 + 滑窗 180

- **核心**：有序性/单调性允许指针不回退，把 O(n^2) 枚举对压成 O(n)。窗口的不变式是灵魂
- **母题**：15 三数之和(中等，对撞+去重) → 3 无重复字符的最长子串(中等，可变窗口) → 76 最小覆盖子串(困难，窗口模板完全体) → 11 盛最多水的容器(中等，指针移动的正确性论证最反直觉)
- **族谱信号**：求最值+连续段 → 3；覆盖/包含 → 76；有序数组找和 → 15
- **训练**：283 移动零(简单)、424 替换后的最长重复字符(中等)（窗口+计数器的标准变体）；76 和 424 各写一遍，对比窗口收缩条件
- **过关**：说清 11 里为什么移动短板是安全的（反证）

### 思维 3：二分 —— 二分查找 365 题

- **核心**：不只是有序数组里找一个数；一切具有单调性的答案空间都能二分。三个层次：查值 → 查边界 → 二分答案
- **母题链**：704 二分查找(简单) → 34 查找边界(中等) → 33 旋转数组(中等) → 875 爱吃香蕉的珂珂(中等，二分答案入门) → 1011 运载能力(中等，同 875) → 4 两正序数组中位数(困难，终极形态)
- **族谱信号**：x 越大越容易/越难满足条件 → 二分答案；旋转/山脉 → 局部有序
- **训练**：704/34/33 三题用**同一套边界模板**写（闭区间 `[l,r]` + `l+r/2` + 收缩规则三分支），体会"模板统一则边界恐惧消失"；875/1011 各写一遍，练"答案空间 [min,max] 的确定"
- **过关**：不跑极端用例也能说清 34 为什么返回的是第一个/最后一个位置

### 思维 4：搜索（DFS/BFS/回溯）—— 394+297+129 = 820 题挂载

- **核心**：显式或隐式的状态空间遍历。回溯 = DFS + 撤销决策；BFS = 按层扩散，天然求最短
- **母题**：200 岛屿数量(中等，flood fill 通用形态) → 46 全排列(中等) → 78 子集(中等) → 22 括号生成(中等，带剪枝的生成) → 102 层序遍历(中等，BFS 模板) → 994 腐烂的橘子(中等，多源 BFS)
- **族谱信号**：见第 2 节映射表
- **训练**：46/77/78 三题连写，体会"排列（used 数组）/组合（start 参数）/子集（每层都收）"的三个分叉点；200 用 DFS 和 BFS 各写一遍（呼应 graph 题单过关标准）；127 单词接龙(困难)练隐式图建邻接
- **过关**：白板默写回溯三件套（选择/递归/撤销），并能解释为什么 46 需要 used 而 78 不需要

### 思维 5：动态规划 —— DP 734 + 记忆化 50

- **核心**：最优子结构 + 重叠子问题。一切功夫在"状态定义"——定义好了转移方程是自然语言
- **母题链（按依赖顺序）**：70 爬楼梯(简单) → 118 杨辉三角(简单) → 198 打家劫舍(中等) → 213 环形版(中等) → 53 最大子数组和(中等，一维扫描) → 64 最小路径和(中等，二维) → 322 零钱兑换(中等，完全背包) → 416 分割等和子集(中等，0-1 背包) → 494 目标和(中等，背包+转化) → 139 单词拆分(中等) → 300 LIS(中等) → 1143 LCS(中等) → 72 编辑距离(中等，二维双串) → 5 最长回文子串(中等，区间/中心) → 32 最长有效括号(困难，状态设计精妙)
- **族谱信号**：见映射表；"打家劫舍族"（不相邻选择）→ 198/213；"凑目标值族"→ 322/518/494（同一题的三次换装：最少硬币/方案数/符号分配）
- **训练**：494 必须先做"正负号 → 子集和"的数学转化再看题解（DP 难题 80% 难在转化不在转移）；322/518/494 三连对比"求最值/求方案数/求可行"的转移差异；300 用 O(n^2) 和贪心+二分 O(n log n) 各一遍
- **过关**：任选一题说出"状态、转移、初始化、遍历顺序、答案位置"五要素；32 能画出样例的 dp 表

### 思维 6：贪心 —— 贪心 486 + 区间族

- **核心**：局部最优 ⇒ 全局最优，且要能**证明**（交换论证：任何最优解都能逐步替换成贪心解）。区间族的通用前置：按右端点/左端点排序
- **母题**：121 买卖股票(简单，一次遍历维护历史最低) → 55 跳跃游戏(中等，维护可达上界) → 435 无重叠区间(中等，区间族母题) → 56 合并区间(中等，排序后线性扫) → 134 加油站(中等，反证/油量前缀)
- **族谱信号**：区间族 → 435/56/452 同一骨架；"能否到达" → 55；"最多跳几步" → 45（55+步数计数）
- **训练**：435 与 452 各写一遍，确认只是把"区间计数"换成"弓箭数"；763 划分字母区间(中等)（贪心 + 哈希边界，综合题）；每题写一句话交换论证
- **过关**：能对 55 说出完整论证："能到 i 则能到一切 ≤ i"——这是贪心题过关的最低证明要求

### 思维 7：栈与单调栈（栈 195 / 单调栈 77）

### 思维 8：链表指针操控（链表 102）

- **母题**：206 反转链表(简单，一切的地基) → 21 合并两个有序链表(简单) → 141/142 环形链表(简单/中等，Floyd 判圈) → 19 删倒数第 N(中等，双间距指针) → 143 重排链表(中等，找中+反转+合并三合一) → 25 K 个一组翻转(困难，206 的模块化组装) → 160 相交链表(简单，双指针浪漫)

### 思维 9：二叉树递归分治（二叉树 219 / 树 308）

- **核心**：把"整棵树的问题"缩小成"左子树+右子树的问题"。写对函数定义（返回什么语义）就赢了一半
- **母题**：104 最大深度(简单) → 226 翻转(简单) → 101 对称(简单) → 236 最近公共祖先(中等，后序聚合) → 105 前序中序构造(中等，分治) → 98 验证 BST(中等，上下界传递) → 230 BST 第 K 小(中等，中序性质) → 124 最大路径和(困难，返回值 vs 全局答案分离) → 297 序列化(困难，前序+空标记)
- **训练**：124 和 236 必须先口述"递归函数返回值的语义"再动笔——这两题的返回值和最终答案不是一回事
