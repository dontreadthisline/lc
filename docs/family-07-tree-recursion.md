# 家族 7：树与递归 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：二叉树/多叉树上的性质判断、构造、路径、祖先
- **原语**：递归函数语义（返回值定义先行）、自顶向下传参（上下界）、自底向上聚合（后序）、层序（队列）
- **锚点**：递归函数返回什么的语义写清楚了吗 → 返回值和最终答案是一回事吗 → 空树/叶子的边界 → 传参还是聚合
- **失效**：需要频繁回跳父指针 → 预建父映射或转图

## 1. 识别与反识别

**正信号**：树的遍历/性质/构造/路径。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 104 最大深度 vs 124 最大路径和 | 104 的返回值 = 答案；**124 的返回值（以本节点向下的单链最大）≠ 答案（可能拐弯的全局最大）**——返回值语义与答案分离是本题全部难点 |
| 98 验证 BST vs 226 翻转 | 98 需要自顶向下携带上下界（父信息传子）；226 纯自底向上（子答案拼父）——传参与返回的分野 |
| 105 构造 vs 102 层序 | 构造用分治（前序定根 + 中序分左右）；层序用队列——递归 vs 迭代两套底盘 |

## 2. 入门讲解

树的递归全部建立在**一个约定**上：先把递归函数的返回值语义说清楚，写进函数注释第一行。`maxDepth(node) = 以 node 为根的子树的最大深度`——语义定了，转移是自然语言：`1 + max(左, 右)`。**写对语义就赢一半**（INDEX 家族 7 核心解法原话）。

**两种信息流向**：

- **自顶向下（传参）**：父的约束流给子。98 验证 BST：每个节点必须落在 `(lower, upper)` 开区间里，区间随递归下传收紧——参数是"祖先链的累积约束"
- **自底向上（聚合）**：子的答案汇成父的答案。236 最近公共祖先：左右子树各回报"见没见到 p/q"，左右都有 → 我是分岔点

**124 的分离术**：递归返回"以我为起点向下的最大单链"（只能选一边），全局答案另用一个外部变量记"经过我的拐弯路径"（两边都要）。**返回值是给父用的，答案是自己算的**——两本账分开记，是树形 DP 的第一课。

**105 构造**：前序第一个是根；在中序里定位根（哈希 O(1)），左段是左子树、右段是右子树；分治递归。**构造题 = 每次从序列里认出根 + 切分剩余**。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 语义化递归 | `f(node) → <语义>`，写清在注释 | 子问题同构 | O(n) |
| 上下界传递 | `f(node, lo, hi)` | 约束可沿路径累积 | O(n) |
| 单链/全局分离 | 返回单链贡献，外部变量记全局答案 | 124 型拐弯问题 | O(n) |
| 前序定根分治 | 前序根 + 中序切分 + 哈希定位 | 前中序唯一确定树 | O(n) |
| 层序 BFS | 队列 + 按层快照 | 见家族 8 | O(n) |
| 序列化 | 前序 + 空标记（`#,`） | 297 型，空节点必须显式 | O(n) |

## 4. 思维锚点（含本仓库半成品实证）

| # | 锚点问句 | 违反后果（实证/经典） |
|---|---|---|
| 1 | **递归函数的返回值语义，一句话写出来了吗？** | 语义含糊的递归 = 边写边猜；124/236 动笔前先口述语义是硬纪律（8020 训练条） |
| 2 | **返回值和最终答案是一回事吗？** | 124 直接返回拐弯路径：父节点拿到拐弯值没法用（它只能接单链），全局解错——**返回值是接口，答案是全局，两本账** |
| 3 | **空树/单叶的边界返回什么？** | `nil` 返回 0 还是 -∞？124 的负权路径：单负叶的最大路径是它自己，返回 0 会抹掉负贡献的正确性 |
| 4 | **约束传参还是子树聚合？** | 98 用聚合（比较左右子树全部节点）O(n²) 超时——上下界传递才是 O(n)；方向选错不是错答案就是超时 |
| 5 | **构造题空段怎么切？** | 105：切分下标越界/左右段空，递归要在 nil 处干净终止 |
| 6 | **序列化的空标记带了吗？** | 297：不带空标记的前序无法唯一重建（不知道左子树哪截断） |

## 5. 数学形式化

**树递归的正确性框架 = 结构归纳**。

- **命题**：若 f 对所有真子树返回正确，则 f(node) 正确
- **证明模板**：基例（空/叶）直接验证；归纳步把 f 的定义按"根 + 左右子树"展开，代入归纳假设 ∎
- **假设**：子问题严格更小且同构（树是严格分叉的归纳结构——与整数的数学归纳同构，归纳对象从 n 换成子树）

**98 的上下界完备性**。

- **命题**：`f(node, lo, hi)` 判定子树内所有节点落在 (lo, hi) 与 BST 定义等价
- **证明**：BST 约束 = 对每个节点的"祖先链约束之交所成区间"；递归下传 `(lo, node.Val)` / `(node.Val, hi)` 恰维护这个交 ∎
- **反例（聚合式判定）**：只比较直接父子，孙辈越界漏检（如右子树的左子树小于根）——深度约束必须传到底

**层序的性质**：队列不变量 = "当前层未出队节点 + 下一层已入队节点"，层边界由快照长度决定——BFS 家族（§8）在树上的直射。

## 6. 迁移与连接

- 递归分治是回溯（家族 9）的骨架：决策树 = 抽象的树
- 树形 DP（家族 10/11 在树上的形态）全部遵循 124 的"返回值/全局答案分离"纪律
