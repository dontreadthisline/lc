# LeetCode 算法题目分类总纲（官方标签实测版）

> 数据来源：leetcode.cn 官方 GraphQL 接口（`problemsetQuestionListV2`，`categorySlug=algorithms`），2026-09-14 经真实浏览器全量抓取**算法分类下全部 3916 题**逐题聚合。所有题数均为官方标签下的精确计数，非记忆、非估算（已剔除数据库/pandas/Shell 等非算法题）。官方标签体系会随时间调整，刷新方法见文末。

## 0. 使用须知：标签是索引，不是教学大纲

- 官方标签是**多对多**的：平均每题挂 3.40 个标签。例：200. 岛屿数量 = 深度优先搜索 + 广度优先搜索 + 并查集 + 数组 + 矩阵。
- 题数反映该考法的出题频率（练习量的参考），**不等于学习顺序**。
- **为什么 170 个标签对应不了 170 个算法分类**：官方标签是检索关键词（用于筛题），不是分类学，它把四种粒度平铺在了一起——① 纯数据结构载体（数组/堆/线段树/Treap 等，约 40 个，不是算法）；② 真正的算法思想层（搜索/二分/贪心/DP/图论等，仅十几个）；③ 同一思想下的具体算法变体（最短路之下的 Dijkstra/BF/Floyd，网络流之下的 Dinic/EK 等）；④ 领域杂项词（数学/几何/博弈/交互等）。且变体标签只是散点细分：排序 556 题里九种具体排序标签合计仅 56 题，最短路 45 题里五个子算法标签合计仅 23 题——一级标签管全集，四级标签管精确制导，粒度故意不一致。
- 本大纲把官方 170 个标签按粒度重组为 12 条学习主线，标签后括号内为官方精确题数。深度题单已有两张：图 → `docs/leetcode-graph-list.md`，堆 → `docs/leetcode-heap-list.md`。
