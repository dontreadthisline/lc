# Quickselect 区间收缩的正确性证明

对应代码：`algo/partation.go` 中的 `findKthSmallest`。

讨论的问题：`n > k` 分支为什么必须收缩成 `[l, b-1]`？既然第 k 小也在 `[l, b]` 里，传 `b` 不行吗？

结论先行：**不行。传 `b` 时"区间里包含目标"依然成立，但算法会陷入不动点，无限递归**。下面先证"传 `b` 必死"（定理 B），再证"传 `b-1` 一定对"（定理 A）。

---

## 0. 记号与前提

设某层调用为 `(l, r, k)`，记：

- 区间大小 $s = r - l + 1$，合法调用满足 $l \le r$ 且 $1 \le k \le s$；
- $p_0$ 为 pivot 的**取值**（即 partition 前 `nums[r]` 的值）；
- `partition` 返回 $b$，记 $n = b - l + 1$。

partition 循环的标准不变量给出三条性质，是全部推理的地基：

> **P1** `nums[l..b-1]` 全部 $< p_0$
>
> **P2** `nums[b..r]` 全部 $\ge p_0$
>
> **P3** 交换 `nums[b] ↔ nums[r]` 后，`nums[b] == p₀`

**P3 的原因**：j 走到 r 时谓词 `p0 < p0` 为假，所以整个循环期间位置 r 从未被写入，$p_0$ 一直待在 r，最后被显式换到 b。

另外 j=r 那步永不使 b 自增，所以 $b \le r$，于是：

$$1 \le n = b - l + 1 \le s$$

### 引理 1（排序结构）

把 `[l, r]` 排序后的序列记为 $S[1..s]$，则：

$$\underbrace{S[1..n\!-\!1]}_{\text{L 段 } [l,\,b-1]\text{ 的排序}} \quad \underbrace{S[n] = p_0}_{\text{pivot}} \quad \underbrace{S[n\!+\!1..s]}_{\text{R 段 } [b\!+\!1,\,r]\text{ 的排序}}$$

**证明**：严格小于 $p_0$ 的元素恰有 $n-1$ 个且全在 L 段（P1、P2），排序后必然占据位置 $1..n-1$；剩下 $s-n+1$ 个元素全 $\ge p_0$，占据位置 $n..s$，其中位置 $n$ 是它们的最小值，而 $p_0$ 在其中且是下界，故 $S[n] = p_0$。位置 $n+1..s$ 的多重集等于 $\{p_0\} \cup R$ 去掉一个 $p_0$ 副本，即恰为 R 段。（用到事实：$\mathrm{sorted}(A \uplus \{p\})$ 删去一个 $p$ 就是 $\mathrm{sorted}(A)$，删除不改变其余元素的相对顺序。）$\blacksquare$

## 定理 B：传 `b` 的版本，只要进入 `n > k` 分支就死循环

直觉上没错的一半：" `[l, b]` 也包含第 k 小" 为真——引理 1 中 $k \le n-1$ 时 $S[k]$ 确实在 L 段，而 L 段 $\subseteq [l, b]$。问题不在找不找得到，在下面这个引理。

### 引理 2（前缀全满足 + 尾元素不满足 ⟹ partition 是恒等变换）

设区间 `[l, r]` 中 `nums[l..r-1]` **全部满足**谓词，`nums[r]` **不满足**。则 partition 执行期间每次 `swap(nums[b'], nums[j])` 都有 $b' = j$（自交换），**数组一个元素都不变**，返回 $b = r$。

**证明**：对循环轮数归纳，证不变量 "$b' = j$ 且数组未变"。

- 初始：$b' = l = j$；
- 归纳步：设某轮开始 $b' = j$。若 $j < r$，由前提 `nums[j]` 满足谓词，执行 `swap(nums[j], nums[j])`（恒等），`b'++`；随后 `j++`，$b' = j$ 恢复；
- $j = r$ 时不满足谓词，不交换。循环结束 $b' = r$。$\blacksquare$

### 定理 B 的证明

设某层调用 `(l, r, k)` 执行完 partition 和交换后 $n > k$，修改版代码递归 `(l, b, k)`。此刻数组状态：

- `nums[l..b-1]` 全部 $< p_0$（P1）
- `nums[b] == p₀`（P3）

而新调用的 pivot 取 `nums[b]`，即还是 $p_0$ —— 恰好构成**引理 2 的前提**：前缀 $n-1$ 个全满足 "$< p_0$"，尾元素 $p_0$ 不满足 "$< p_0$"。于是：

1. 新层 partition **不改变数组**，返回 $b' = b$（引理 2）；
2. 新层交换 `nums[b'] ↔ nums[r']` 即 `nums[b] ↔ nums[b]`，恒等；
3. $n' = b' - l + 1 = n > k$，依旧不触发 `n == k`，再次递归 `(l, b, k)`。

即新调用与旧调用**状态完全相同**（数组、l、r、k 逐项相等）。对递归深度归纳：之后每一层都与这一层一模一样，$n$ 永远停在初始值且 $n > k$。无限递归直至栈溢出。$\blacksquare$

注意证明未使用任何额外输入假设——**不是"某些输入会死"，是这个分支一进必死**。

### 实例：`[3, 1, 2], k = 1`

| 层 | (l, r, k) | pivot | partition 后 b | n | 动作 |
|---|-----------|-------|----------------|---|------|
| 1 | (0, 2, 1) | 2 | 1，数组变 `[1,2,3]` | 2 | n > k → 递归 (0, 1, 1) |
| 2 | (0, 1, 1) | nums[1] = 2 | 1，**数组不变** | 2 | n > k → 递归 (0, 1, 1) |
| 3 | (0, 1, 1) | 2 | 1，**数组不变** | 2 | …… 恒等复现 |

## 定理 A：传 `b-1` 的现行代码正确且终止

对区间大小 $s$ 做强归纳。命题 P(s)：任何合法调用 `(l, r, k)`（$s = r-l+1$）在有限步内返回 `[l, r]` 当前内容的第 k 小值。

**基础 $s = 1$**：$l = r,\ k = 1$。j=r 时谓词为假，$b = l$，交换恒等，$n = 1 = k$，返回唯一元素。一步终止且正确。

**归纳步**：设 P(1..s-1) 成立，证 P(s)（$s \ge 2$）。得到 $b$ 与 $n \in [1, s]$，三种情形：

**情形 1：$n = k$**。返回 `nums[b]`。由引理 1，$S[n] = p_0 = $ `nums[b]`，正确，终止。

**情形 2：$n > k$**（故 $k \le n-1$）。由引理 1，$S[k]$ 落在 $S[1..n-1]$ 内，即：

$$\text{全区第 } k \text{ 小} = \text{L 段 } [l,\, b-1] \text{ 的第 } k \text{ 小}$$

递归 `(l, b-1, k)` 合法：$1 \le k \le n-1$ 恰为新区间容量。新区间大小 $n - 1 < s$，归纳假设给出正确返回。

**情形 3：$n < k$**（故 $k \ge n+1$）。由引理 1，$S[k]$ 落在 $S[n+1..s]$ 内，即：

$$\text{全区第 } k \text{ 小} = \text{R 段 } [b\!+\!1,\, r] \text{ 的第 } (k - n) \text{ 小}$$

递归 `(b+1, r, k-n)` 合法：$k - n \ge 1$，且 $k - n \le s - n$ 恰为新区间容量。新区间大小 $s - n < s$，归纳假设适用。

**终止性**：两个递归分支的区间大小分别是 $n-1$ 与 $s-n$，均 $< s$。正整数严格递减，链长不超过 $s$，递归深度有限。$\blacksquare$

## 回到最初的问题

> "n < k 时传 `b+1, k-n` 能理解；n > k 时，`[l, b-1]` 和 `[l, b]` 里都藏着第 k 小，选 `[l, b]` 不行么？"

"[l, b] 包含第 k 小" 为真，但算法的推进机制不是"区间包含目标"，而是**每层消耗一个 pivot 换取区间严格缩小**——这是定理 A 终止性的全部来源。传 `b` 等于让刚定位完的 pivot 下一轮继续当 pivot：引理 2 证明这种局面下整个函数体退化为恒等变换，状态一比特都不变，$n$ 与 $k$ 的距离永远冻结在进入分支那一刻。

两个分支永远写成 $[l, b-1]$ 和 $[b+1, r]$、**b 从不出现在下一层**，同时保证了两件事：

1. **终止性**：每层至少消耗 pivot 一个元素，区间严格缩小；
2. **`k-n` 的语义**：L 段整段 $n$ 个元素已定位完毕、退出竞争，R 段的第 $(k-n)$ 小才是全区的第 $k$ 小。

这与快速排序的递归结构完全同构——快排同样把 pivot 归位后从两个子区间中排除掉它。
