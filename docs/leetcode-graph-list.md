## 刷题建议

1. **顺序即依赖**：阶段 3 依赖 2 的 BFS 手感；阶段 6 可以和 5 并行；7 的 MST 依赖 6 的 Kruskal
2. **过关标准**：每阶段先做带 [验] 的（最典型），能不看题解写出两种解法（如 200 用 DFS 和 BFS 各一遍、684 用 DFS 和并查集各一遍）再进下一阶段
3. **两两对照着刷**效果最好：1631 vs 778（同一模型）、994 vs 1162（同构聚合）、207 vs 802（正反拓扑）、542 vs 317（min 与 sum 聚合的分界）
4. 会员题（286/317/269/323/305/444）若无会员可跳过，考点在免费题中均有平替
