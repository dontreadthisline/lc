# 家族 9：回溯 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**："所有方案/全排列/所有子集/所有组合/N 皇后"；答案空间指数级，只要列举不要计数
- **原语**：三件套（选择→递归→撤销）、三叉点（排列 used / 组合 start / 子集每层收）、剪枝
- **锚点**：解的形状（叶子收集还是沿途收集）→ 去重靠 used 还是排序+start → 剪枝条件写在哪 → 撤销必须与选择严格对称
- **失效**：只要个数不要枚举 → DP/数学；n > 25 的指数空间 → 换思路（折半、状压 DP）

## 1. 识别与反识别

**正信号**：返回**所有**解的列表；n ≤ 20 上下的规模暗示（复杂度反推表：n ≤ 12 可 O(n!·n)）。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 46 全排列 vs 77 组合 | 解空间 = 序列（有序，[1,2]≠[2,1]）→ used 防重取；解空间 = 集合（无序）→ start 保证只向前取 |
| 78 子集 vs 77 组合 | 子集：**每个节点**都是解（沿途收）；组合：只有**叶子**是解（长度凑够才收）——同骨架差一行 |
| 回溯 vs DP | 要**列举**所有方案 → 回溯（输出本身指数大）；只要**计数/最优** → DP（多项式内压缩信息） |
| 22 括号生成 vs 20 括号匹配 | 生成带约束的所有串 → 回溯 + 剪枝（左括号余量、右括号合法性）；验证给定串 → 栈（家族 5） |

## 2. 入门讲解

回溯 = **决策树的深度优先遍历**。每个非叶节点是一个"部分解"，每条边是一次选择，叶子（或满足条件的节点）是完整解。骨架只有三件套：

```go
func backtrack(路径, 选择列表) {
    if 满足结束条件 { 收藏路径; return }
    for 选择 := range 选择列表 {
        做选择          // 路径.push(选择)
        backtrack(路径, 新选择列表)
        撤销选择        // 路径.pop()   ← 三件套的第三件，漏了就串解
    }
}
```

**三叉点**（46/77/78 三题连写的意义）：同一个骨架，防重的机制三选一——

- **排列**：任何位置可取任何剩余元素 → `used[]` 标记
- **组合/子集**：只向后取，天然无序去重 → `start` 参数（下一层从 `i+1` 起）
- **子集**：不设长度门槛，进入节点就收

**剪枝**：在递归**之前**判死路。22 的两条（右括号数不能超左、左括号不能超总额）把指数树砍掉大半；51 的列/对角线冲突检测同理。**剪枝不改变正确性（砍掉的枝不含解），只改变速度**——这条性质让你敢于激进剪。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 三件套骨架 | 选择/递归/撤销 | 解可增量构造、可撤销 | O(解空间) |
| used 防重（排列） | 全局 bool 数组 | 解是有序序列 | O(n!·n) |
| start 前进（组合） | 层间下标递增 | 解是无序集合 | O(C(n,k)·k) |
| 沿途收集（子集） | 进节点即 append 拷贝 | 任何前缀都是合法解 | O(2ⁿ·n) |
| 剪枝 | 递归前判可行性 | 剪掉的分枝**必不含解** | 只快不错 |
| 输入含重复元素的去重 | 排序 + 同层跳过 `nums[i]==nums[i-1]` | 90/40 型 | — |

## 4. 思维锚点（本族未开垦，列经典翻车模式待实战填充）

| # | 锚点问句 | 经典翻车（待本仓库实证） |
|---|---|---|
| 1 | **解在叶子还是沿途收？** | 组合题进节点就收：收到一堆非法前缀——先想清楚解的形状再动笔 |
| 2 | **收藏的是拷贝还是引用？** | 收 `path` 引用：回溯撤销后收藏里的"解"全变成空——**收快照** |
| 3 | **撤销和选择对称吗？** | 做选择改了两个状态（路径+used），撤销只回滚一个：后续枝全部污染 |
| 4 | **去重机制选对了吗？** | 组合用 used：同一集合按不同顺序重复收；排列用 start：直接漏解 |
| 5 | **剪枝条件砍的是死枝吗？** | 剪掉活枝 = 漏解——剪枝前必须能说"这枝必无解"，说不出来就不剪 |
| 6 | **输入有重复元素排序了吗？** | 不排序直接跳同值：同值不同位置的分支混乱重复 |

## 5. 数学形式化

**决策树遍历定理**。

- **命题**：三件套遍历恰生成解空间中每个解恰好一次
- **证明**：树节点 ↔ 部分解，父子 ↔ 增量一步；DFS 到叶子 ↔ 构造完成；used/start 保证树中无重复路径（同层选择互异 + 层间约束传递）⟹ 叶子与解双射 ∎
- **假设**：选择可撤销（栈式构造）；解空间有限
- **反例**：不可撤销的全局副作用（修改了输入数组没还原）——树被遍历过程自己改写，双射破坏

**复杂度下界的诚实**：输出规模本身就是 O(解个数 × 解长)，回溯达到这个下界——**它不是"笨办法被优化"，它就是输出敏感的最优**。排列 n!、子集 2ⁿ，n > 25 时任何枚举都死，要么只要计数（DP），要么折半meet-in-middle。

**剪枝保真性**：剪枝条件 P(部分解) ⟹ 该子树无完整解。证明义务在剪枝者——22 的"右>左必死"由括号串前缀合法性传递；51 的对角线冲突由放置的不可撤销性。**P 是定理不是直觉**。
