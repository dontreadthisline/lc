# 家族 13：贪心与区间 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：区间重叠/不重叠/合并/覆盖；"能否到达/最多几个/最少几支箭"；跳跃、加油站
- **原语**：按右端点排序（区间调度）、合并扫描（前缀 max）、交换论证（正确性证明）、构造可达域（1798）
- **锚点**：排序键选谁（右端点还是左端点）→ 局部最优是什么 → 交换论证说得出来吗 → 区间开闭
- **失效**：证明不了交换论证 → 老老实实 DP；需要"恰好/所有方案" → 回溯

## 1. 识别与反识别

**正信号**：区间集合 + 计数/选择；一步决策看似独立、问最少/最多。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 435 无重叠区间 vs 56 合并区间 | 435 **选**不重叠的最多者 → 按右端点排序留最早结束的；56 **并**重叠者 → 按左端点排序逐段吸收——问题方向（选/并）决定排序键 |
| 55 跳跃游戏 vs 45 跳跃游戏II | 55 问能否到达（维护可达上界）；45 问最少几步（维护当前层边界+下一层边界——层序思想回连家族 8） |
| 贪心 vs DP | 每步选择不依赖未来细节 → 贪心 + 交换论证；选择间有交换依赖 → 家族 10 |

## 2. 入门讲解

贪心的信条：**局部最优 ⟹ 全局最优**——但这必须**证明**，不能靠直觉（家族 13 核心解法：交换论证是过关门槛）。

**区间调度原型（435/452）**：最多选多少个互不重叠区间？按**右端点**排序，每轮选"结束最早的"，丢弃与它重叠的。直觉：早结束的给后面留最多空间。**交换论证**（证明见 §5）把它从直觉升格为定理。452 射气球与 435 是同一骨架换皮——区间计数换成箭数。

**合并（56）**：按**左端点**排序，扫一遍：新区间左端 ≤ 当前段右端 → 吸收（右端取 max）；否则开新段。与 435 的排序键相反，因为问题从"选"变成"并"。

**跳跃游戏（55/45）**：`farthest = max(farthest, i + nums[i])`——可达域单调扩张，i 走不过 farthest 即断路。45 在此之上维护"当前步数的边界"，跨界就步数+1——**贪心的骨架 + BFS 的分层思想**。

**加油站（134）**：经典反证——若从 A 出发到 B 油尽，则 A..B 之间任何起点都到不了 B（油量前缀差的线性性）→ 直接从 B+1 重启。**反证 + 前缀量**是贪心里最数学味的工具。

**1798 构造连续值（题单收编题）**：硬币从小学推导可达域 `[0, x]`——下一枚 `v ≤ x+1` 则扩到 `[0, x+v]`；`v > x+1` 则 `x+1` 永远缺货。**可达域的归纳结构**是本题的全部（§5）。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 右端点排序调度 | sort by end + 逐个选不重叠 | 证明交换论证 | O(n log n) |
| 左端点合并 | sort by start + 吸收/开段 | — | O(n log n) |
| 可达上界 | `far = max(far, i+step)` | 可达性单调 | O(n) |
| 反证重启 | 局部失败段整体跳过 | 失败段的传递性可证 | O(n) |
| 可达域构造 | 维护 [0,x]，v ≤ x+1 扩域 | 输入排序 | O(n log n) |
| 交换论证 | 任何最优解可逐步换成贪心解 | 每题现证 | — |

## 5. 数学形式化

**区间调度定理（435）**。

- **命题**：按右端点升序，贪心选择的互不重叠区间数 = 最优值
- **证明（交换论证）**：设贪心解 G = g₁,g₂,…（右端点递增），最优解 O = o₁,o₂,…。归纳断言 `end(g_k) ≤ end(o_k)`：k=1 时贪心选了最早结束者；若 `end(g_k) ≤ end(o_k)`，则 `o_{k+1}` 与 g_k 不重叠 ⟹ 它是 g_k 之后的候选，贪心第 k+1 步选的最早者必有 `end(g_{k+1}) ≤ end(o_{k+1})`。故 O 有 m 个 ⟹ G 至少 m 个 ∎
- **假设**：区间端点可比较；"不重叠"判定对称
- **反例（假设违规）**：带权区间调度（每段价值不同）——交换不等价，贪心失效，退回 DP

**可达域归纳（1798）**。

- **命题**：硬币排序后，可达值域恰为 `[0, x]`，其中 x 由"v ≤ x+1 则 x += v"逐枚推进
- **证明**：归纳——当前可达 [0,x]，下一枚 v：v ≤ x+1 时新子集和集合 = [0,x] ∪ [v, x+v] = [0, x+v]（v ≤ x+1 保证无缝拼接）；v > x+1 时 x+1 不可达（其余硬币 ≥ v > x+1，任何含 v 的和 > x+1，不含 v 的和 ≤ x）∎
- **假设**：每枚硬币恰用一次、值非负
- **推论**：跳过的硬币对可达域无贡献——这就是"排序后贪心推进"的正确性

**加油站反证的传递性**：从 A 出发到 B 油尽 ⟺ 段内油量前缀差的最小值出现在段内某点 ⟹ 段内任何起点的前缀差更差 ⟹ 全段作废，O(n) 单遍 ∎。
