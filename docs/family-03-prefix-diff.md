# 家族 3：前缀和与差分 —— 专题讲解

> 差分的完整定理与证明独立成篇：`docs/diff-array-math.md`，本文引用不重复。

## 0. 速查卡（复习用）

- **信号**：子数组和满足某条件且**元素可负**；静态数组反复区间查询；区间批量修改；由最终状态反推最少操作
- **原语**：配对计数（φ 键 + 哈希查账）、前缀表查询 O(1)、差分记账 + 一遍还原、`r(x)` 余数归一
- **锚点**：内层语义（查账/查表/记账）→ 配对键 φ 是谁 → 种子种了吗 → 先查后插、插入跟上查询 → 差分开闭 + 还原顺便干嘛 → 从定义域起点预热
- **失效**：含负数的不等式计数（≥/≤）→ 树状数组/归并（题单外）

## 1. 识别与反识别

**正信号**：连续子数组的和 + 条件词（等于 k / 被 k 整除 / 区间内）；"每个区间 [l,r] 加 v，求最终/查询"；矩阵反复求区域和。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 560 和为K vs 930 和相同二元子数组 | 560 元素可负——滑窗死，只有本族；930 元素非负——atMost 相减（家族 2）更快。同问"恰好"，元素符号决定家族 |
| 1109 航班预订 vs 1094 拼车 | 同为差分：1109"到 last 站仍被服务"（闭区间，下岗 last+1）；1094"到 to 站已下车"（半开，下岗 to 本身）。**开闭是题面语义，不是模板属性** |
| 1526 vs 1109 | 1109 给操作求状态（Δ 方向）；1526 给状态求最少操作（逆 Δ 方向，且是优化问题） |
| 304 区域和 vs 1109 记账 | 同一根前缀和的两种用法：304 预处理 + 反复查表（读多写少）；1109 记账 + 一次还原（写多读少一次） |

## 2. 入门讲解：560 的施工图

560（和为 K，元素可负）暴力：双重循环求和。**第一换元**：`P[t] = nums[0..t-1]` 之和，则 `sum(i..j) = P[j+1] − P[i]`——O(n²) 个子数组压成 O(n) 个前缀。**第二换元**：条件移项 `P[j+1] − P[i] = k ⟺ P[i] = P[j+1] − k`——左边只含 i，右边只含 j，**配对条件解耦**。从左到右扫，问哈希表"之前有多少个前缀等于 `P[j+1] − k`"。

通用施工图：**O(n²) 配对 → 固定一方当外层，把另一方解成 O(1) 查询**——001 到 560 到 974，同一张图用了三次，只是键的形状在变。

三张面孔各自的入口：

- **查账**（560/974/1513）：内层在数配对 → 键可变形的哈希计数
- **查表**（304）：预处理前缀表，之后任意区间和 O(1) 读——无哈希
- **记账**（1109/1094/1854/1893）：区间加不逐点执行，只记两个边界事件，一遍前缀和还原——无哈希

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 配对计数 | 流式维护 `m[φ(P)]`；每轮 `res += m[φ(P[j+1]) 的配对键]` 后插自身 | 条件可改写为 φ(对方)=φ(我)；种子 φ(P₀) 先入账 | O(n) |
| `r(x)` 余数归一 | `((x%k)+k)%k` → [0,k) 类代表 | k > 0 | O(1) |
| 前缀表查询 | `P[i][j]` 预处理后，区域和四角读出 | 数组静态（不修改） | 预处理 O(nm)，查询 O(1) |
| 差分记账 | 区间 (l,r,v) → `diff[l]+=v; diff[r+1]-=v`；一遍 `run += diff[i]` 还原 | 开闭由题面定；还原从定义域起点起链 | O(m+n) |
| 逆差分计数 | 给 f 求最少区间加：`Σ max(0, Δf(i))` | — | O(n) |

## 4. 思维锚点（含本仓库实证）

| # | 锚点问句 | 违反后果（实证） |
|---|---|---|
| 1 | **内层循环的语义是什么？** 数配对→查账；范围求和→查表；区间加→记账 | 选错面孔是本族第一大坑：拿哈希硬做 1109，把区间加当配对，无处下手 |
| 2 | **配对键 φ 是谁？每处键走同一个 φ 了吗？** 条件解不出"对方= f(我)"就造 φ：恒等（560）、取模归一（974）、`P[x]−x`（1513，和=长度） | 560 键写成 `k+P[j]`（查自己不查对方）；974 插入用原值、查询用余数（两套坐标系配不上对） |
| 3 | **种子种了吗？** 空前缀是合法左方（从下标 0 开头的子数组）：和 0、积 1 | 560 循环从 1 起：`P[0]=0` 没入账，`[3], k=3` 这类全丢；对照家族 2 的空窗贡献 0、238 的 `left[0]=1`——单位元第三次登场 |
| 4 | **先查后插了吗？插入跟上查询的右端了吗？** | 560 插入 `P[j]` 查询 `P[j+1]`：插入慢一格，所有单元素子数组蒸发；k=0 先插后查则自己配自己 |
| 5 | **差分：开闭从题面读了吗？还原时顺便干嘛？** | 1109 下岗写 first+1（应为 last+1，单站预订恰好掩盖）；1854 只记人口丢了年份、取 min 反向——**记账是模板活，收尾是读题活** |
| 6 | **还原从定义域起点预热了吗？** | 1893 从 left 起扫：left 之前的事件没进 run，覆盖来自窗口外的用例全挂。`f(i)=f(i−1)+diff[i]` 的链必须从基点起算；窗口是检查范围不是累积范围 |

## 5. 数学形式化

**配对计数定理**。$P_0 = 0$，$P_t = \sum_{u<t} a_u$，$S(i,j) = P_{j+1} - P_i$。

- **命题**：条件可分解为 $\varphi(P_{j+1}) = \varphi(P_i)$ 时，流式计数正确
- **证明**：双射——每个满足条件的对在其右端点那轮恰被数一次 ∎
- **假设**：φ 在全称定义下良定义且 O(1) 可算；**键的构造在插入与查询两端一致**（同一个 φ）
- **反例**：974 的截断取模——Go 的 `%` 余数跟被除数同号，`-5 % 3 = -2`，而 −5 与 1 同余。不归一到 [0,k) 类代表，同一余数类被劈成两个键（`[3,−2]` 型数据全丢配对）。同余格的证明：带余除法存在唯一 ⟹ r ∈ [0,k) 是每类唯一代表

**望远镜求和与前缀表**。$\Sigma\Delta = \mathrm{id}$：$\sum_{u \le i}(f(u) - f(u{-}1)) = f(i) - f(0)$，中间项两两相消。

- **假设**：基点值良定义（f(0) 已知，通常为 0/单位元）
- **反例**：锚点 6 的 1893——不从基点起链，f(left) 依赖的 `diff[0..left]` 没被累计，读出的不是 f 而是残差

**304 二维容斥**。$P[i][j] = \sum_{u<i, v<j} a[u][v]$，区域和 $= P[r_2{+}1][c_2{+}1] - P[r_1][c_2{+}1] - P[r_2{+}1][c_1] + P[r_1][c_1]$。

- **证明**：逐格分析净贡献系数——目标子矩阵内的格被两个 "+" 项与两个 "−" 项各覆盖恰两次，净系数 1；外部格的四种部分包含情形互相抵消，净 0 ∎
- **假设**：数组静态。动态点修改需要 BIT/线段树（失效边界）

**差分转化定理**：区间加的差分支撑集只有边界两点（五种情形逐位置验证），Δ 线性 ⟹ 压缩表示可逐操作翻译后叠加——完整证明见 `docs/diff-array-math.md` §3–5。**1526 逆用**：答案 $= \sum_i \max(0, \Delta f(i))$（下界：每个正差分处必须有新操作垫高；上界：按差分正负切分构造等数方案）。

## 6. 迁移与连接

- 001（家族 1）是本族查账面孔的祖先；atMost（家族 2）在非负域可替代本族，含负域只有本族接得住
- 含负数的不等式计数（LC 327 族，题单外）：哈希只会等值，升级树状数组/归并数点对
- 差分的动态版（在线区间加+区间查）→ 树状数组/线段树
- 值域 10⁹ 的差分：裁剪到窗口（求交换基点）或排序事件只扫非零点（离散化）——见 `diff-array-math.md` §7
