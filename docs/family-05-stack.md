# 家族 5：栈与单调栈 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：最近匹配（括号、消对子）；"下一个/上一个更大（小）元素"；直方图/柱状面积；嵌套结构
- **原语**：裸栈（LIFO 匹配）、单调栈（找最近更大/小）、栈内保持某种序
- **锚点**：什么进栈（下标还是值）→ 弹出条件即答案 → 栈内不变量是什么 → 空栈/循环数组处理
- **失效**：需要随机访问中段、需要双端（→双端队列/堆）

## 1. 识别与反识别

**正信号**："匹配/抵消/嵌套"（括号、消相邻对）；"最近的比它大/小的"（每日温度、下一个更大）；柱状图矩形。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 20 有效括号 vs 22 括号生成 | 匹配给定的 → 栈（家族 5）；生成所有的 → 回溯（家族 9）——"验证"和"枚举"分家 |
| 739 下一个更大 vs 有序数组找位置 | 流式问"下一个更大" → 单调栈 O(n)；若数组静态且反复查 → 排序+二分（家族 4）。流式 vs 静态决定结构 |
| 42 接雨水 vs 84 柱状图 | 42 是"每个位置左右最大值"的包装，双指针/单调栈/前缀最大三解；84 是单调栈完全体（宽度在弹出时结算） |

## 2. 入门讲解

**裸栈（20）**：括号匹配的本质是"最近未匹配的同类"——左括号进栈，右括号找栈顶配对（配对后弹出），任何时刻栈里都是"还欠着的左括号"。栈的定义性用途：**维护最近的未处理元素**。

**单调栈（739）**：找"下一个更大的"。暴力对每个 i 向右扫，O(n²)。观察：扫到 x 时，栈里那些**比 x 小**的元素，答案已经确定（就是 x！）——弹出去结算，剩下的把 x 压栈。栈内天然保持**从底到顶递减**，这就是不变量。

```
for i, x := range nums {
    for 栈非空 && x > nums[栈顶] {
        栈顶出栈，答案[栈顶] = i     ← 弹出条件即答案
    }
    压入 i
}
```

**84（完全体）**：柱状图最大矩形。以每根柱为高度的最大矩形，宽度 = 左右第一个更矮柱之间——单调栈（递增）在弹出时结算宽度，哨兵柱收尾清栈。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 裸栈匹配 | 左进栈、右找栈顶配对弹栈 | 配对关系可 O(1) 判定 | O(n) |
| 单调栈（下一个更大） | 压栈前弹出所有 ≤/＜ 者，弹出即结算 | "更大更早出现"的答案可结算 | 摊还 O(n) |
| 循环数组版 | 下标取模跑 2n 轮，或拼接数组 | 503 型 | O(n) |
| 弹出结算宽度 | `ans[top] = (i - top) * h` 型 | 84/42 型几何结算 | O(n) |

## 5. 数学形式化

**摊还定理**：每个元素至进栈一次、出栈一次，总操作 2n，O(n)。

- **证明**：出栈条件单调，已出栈者不再入栈；操作序列被 n 次入栈完全支付 ∎
- **假设**：入栈主体互异下标（同一下标不重复入栈）
- **反例**：若弹出后又压回（结算不彻底），摊还破产退化为 O(n²)

**单调栈正确性**（以"下一个更大"为例）。

- **命题**：元素 t 在 x 到来时被弹出 ⟺ x 是 t 的下一个更大元素
- **证明**：t 能留在栈中直到 x，说明 (t, x) 之间没有比 t 大的元素（否则 t 早已被弹出）；x > t 由弹出条件给出——两个事实合起来 x 恰是"下一个更大" ∎
- **不变量**：任意时刻，栈底到栈顶严格递减；栈中元素是"尚未见到下一个更大"的所有候选
- **反例（假设违规）**：弹出条件写 `>=` 时，等值元素被提前弹出，"下一个更大"变成"下一个 ≥"——语义偏移在重复元素上现形

**42 的三种视角等价性**：位置 i 的积水 = `min(左最大, 右最大) − h[i]`。前缀最大（家族 3 查表思想）、双指针（家族 2，维护两侧已见最大）、单调栈（弹出时结算横向水层）——三解同源，是 P0 思维大复习题。

## 6. 迁移与连接

- 单调栈是"流式 lowerBound"：家族 4 在静态有序上二分，本族在流上用栈维持序
- 滑动窗口最大值（239，题单外）= 单调队列——栈的双端变体
- 表达式求值（逆波兰）是裸栈 + 优先级的扩展形态

## 7. 深挖篇：单调栈的解剖（含 0503 实证翻车）

### 7.1 本仓库实证翻车：0503 循环数组（做错中，恒返回空）

错版骨架：栈只在空时入栈、res 从不追加——**根本没建立"谁等谁"的关系**。诊断：函数返回空/长度 0 且无 panic = 状态机没转起来。

### 7.2 单调栈在维护什么：等待队列

一句话：**栈里存的是"还没等到自己'下一个更大元素'的下标"，按值单调**（下一个更大 → 栈内值递减栈底到栈顶……方向取决于题型）。

三个时机，各对应一收获：
```
新元素 x 到来:
  while 栈非空 && x 满足"清算条件"(如 x > 栈顶值):
      栈顶出栈 —— x 就是它的"下一个更大元素", 此刻收获答案
  x 入栈 —— 开始自己的等待
遍历结束:
  栈里剩余的 —— 没有下一个更大, 答案 -1 (0503) / 由右边界收获 (084)
```

**为什么 O(n)**：每个下标入栈一次、出栈至多一次——总操作 2n，摊还 O(1)。这不是直觉，是摊还分析的入门例。

### 7.3 循环数组 = 逻辑 2n 遍历（0503 的正确形态）

```
for i := 0; i < 2*n; i++ {
    x := nums[i % n]
    ...正常清算逻辑...
}
// 收答案只在 i < n 的清算发生(第二遍只为"绕回来"提供更大元素)
// 哨兵替代法: nums 后追加 -∞, 或第二遍结束统一给栈内残留 -1
```
两个等价技巧：`i % n` 走 2n 遍；或数组拼接一遍。**收答案限定前 n 个清算**，否则答案被第二遍重复写。

### 7.4 分界：什么时候想起单调栈

信号清单（满足其一即考虑）：
- 题目问"**下一个/上一个** 更大/更小/满足 P 的元素"（739/503/496）
- "以 i 为最值的最大区间"——出栈时机收获宽度（084 柱状图、042 接雨水的双指针/栈双解）
- 每个元素只关心**一侧第一个破单调的位置**

084 的收获公式（出栈时算面积，栈内保持升序）：
```
h = heights[出栈下标]
宽 = i - (新的栈顶) - 1        // 左边界是弹出后的栈顶(前驱), 右边界是当前 i
```

### 7.5 操作清单

1. 先写出暴力 O(n²)（每个 i 向右/左扫描到第一个更大）——它就是"等待"的语义
2. 栈存下标不存值（要算宽度/距离）
3. 清算条件、入栈、收尾三时机各自收获什么，写代码前用 3 个元素手推
4. 循环数组 → 2n 遍 + 前半收答案
5. 空栈/单元素/全单调序列三个边界用例必测
