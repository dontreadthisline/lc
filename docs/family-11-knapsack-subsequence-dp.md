# 家族 11：背包与子序列 DP —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：从集合里"选/不选"凑目标；容量约束；两序列比对（公共/编辑）
- **原语**：0-1 背包（倒序）、完全背包（正序）、三态（最值/方案数/可行）、LIS（O(n²) 与贪心+二分）、LCS/编辑距离（二维双串）
- **锚点**：物品可重复吗（遍历顺序）→ 求最值/方案数/可行（转移的 max/+/‖）→ 维度谁做外层（物品还是容量）→ 一维滚动时方向对吗
- **失效**：容量值域过大（10⁹）→ 按值域离散化或换贪心/数学

## 1. 识别与反识别

**正信号**：给定物品/数字集合 + 目标（和、容量、长度），问最多装多少 / 几种装法 / 能否恰好。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 322 零钱兑换 vs 416 分割等和子集 | 硬币**无限**（完全背包，容量正序）；石头**各一**（0-1 背包，容量倒序）——同一个 dp 表，遍历方向差一位，语义天壤 |
| 416 vs 494 目标和 | 416 问可行（bool 表）；494 问方案数（int 表）且需先做"正负号→子集和"的**数学转化**——DP 难题八成难在转化不在转移 |
| 300 LIS vs 1143 LCS | 单序列（一维状态+二分优化）；双序列（二维状态）——序列条数决定状态维数 |
| 背包 vs 回溯 | 只要最优值/方案数 → DP；要**列出所有方案** → 家族 9 |

## 2. 入门讲解

背包族的统一叙事：**每件物品做一次"选/不选"的决策，状态 = 已决策物品 + 剩余资源**。

**0-1 背包**：`dp[c]` = 容量 c 下的最优。`for 物品 { for c 从大到小 { dp[c] = max(dp[c], dp[c-v] + w) } }`。**倒序的理由**：一维滚动时 dp[c-v] 必须还是"上一件物品"的值——正序会让同一件物品被选两次（0-1 变完全）。

**完全背包**：物品无限，正序即可——"被选两次"不再是 bug 而是**语义**。

**三态（322/518/416 同题三换装）**：

- 最值：`dp[c] = min(dp[c], dp[c-v] + 1)`
- 方案数：`dp[c] += dp[c-v]`（518）
- 可行：`dp[c] ||= dp[c-v]`（416 用 bitset 更省）

**494 的转化示范**：正负号分配 `sum(+) − sum(−) = target`，加总变形得 `sum(+) = (total + target) / 2`——正号集合是子集选取问题，0-1 背包数方案。**转化先行，转移是体力活**。

**LCS（1143）**：`dp[i][j]` = 两串前 i/j 位的最长公共子序列。尾字符相等则吃掉两个尾，否则丢一个尾取大——**双串 DP 的转移 = 对两个尾字符的三种处置**。编辑距离（72）同表换转移：吃掉/插入/删除/替换四种操作的最小代价。

**LIS 两档**：O(n²) 转移 `dp[i] = max(dp[j]+1 for j<i, a[j]<a[i])`；O(n log n) 维护 `d[k]` = 长度 k+1 的所有递增子序列的最小尾——新元素二分找位置替换（家族 4 的 lowerBound 做内芯）。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 0-1 背包 | 物品外层、容量**倒序** | 每件至多一次 | O(n·C) |
| 完全背包 | 物品外层、容量**正序** | 物品无限 | O(n·C) |
| 三态转移 | max / += / \|\|= | 目标类型明确 | O(n·C) |
| 双串 DP | `dp[i][j]`，转移处置两串尾字符 | 两序列 | O(mn) |
| LIS（贪心+二分） | d 数组维护最小尾，lowerBound 替换 | 严格递增可二分 | O(n log n) |
| 子集和转化 | 正负/分组问题 → sum(子集)=T 的背包 | 转化等式可推 | — |

## 4. 思维锚点（含经典翻车模式，本族未开垦）

| # | 锚点问句 | 经典翻车（待本仓库实证） |
|---|---|---|
| 1 | **物品可重复吗？一维滚动方向对吗？** | 0-1 写成正序：一件物品被选两次，416 出"重复计数"的假可行 |
| 2 | **求什么？转移算子选对了吗？** | 方案数写成 max：518 只得"能否凑出"，数目全丢 |
| 3 | **转化做了吗？** | 494 硬想"正负号 DP"：状态里带符号维度爆炸——先做代数转化降维 |
| 4 | **初始化的 0/1 语义？** | 方案数 dp[0]=1（空集是一种）；可行 dp[0]=true；最值 dp[0]=0——**dp[0] 是"什么都不选"的语义锚**（家族 1/3 的单位元思想第 N 次登场） |
| 5 | **LIS 的 d 数组是真实子序列吗？** | d 只是"各长度最小尾"的档案，**拼不出真实 LIS**——要输出序列得记前驱 |
| 6 | **容量外层物品内层行不行？** | 求方案数且物品有序时，循环内外交换会改变计数语义（组合数 vs 排列数，518 的经典陷阱） |

## 5. 数学形式化

**背包转移的正确性**。

- **命题**（0-1）：倒序遍历下，`dp[c]` 处理完第 i 件后 = 前 i 件、容量 c 的最优
- **证明**：归纳——倒序保证读到的 `dp[c-v]` 尚未被本轮（第 i 件）更新，即"前 i−1 件"的值；转移恰枚举"不选/选第 i 件"两种决策 ∎
- **假设**：物品同质可合并计数
- **反例**：正序遍历读到的 `dp[c-v]` 已含第 i 件——同一物品重复入选，0-1 语义破坏（恰为完全背包语义——**一个遍历方向 bug 等于换了一道题**）

**LIS 贪心+二分的正确性**。

- **不变量**：d 严格递增；`d[k]` = 长度 k+1 的递增子序列的最小可能尾
- **证明**：新元素 x 替换 d 中第一个 ≥x 的位置——保持递增（x 比被替换者小且大于前驱）且不破坏其余项的最小性；长度即当前 LIS 长 ∎
- **假设**：只求长度；d 非真实子序列（锚点 5）

**LCS 转移的完备性**：最优解中两串尾字符"配对消费"或"至少一个被丢"三分情况穷尽所有形态，取 max 覆盖——双串 DP 的转移设计 = **对尾字符的处置分类**，编辑距离同法扩到四种编辑操作 ∎。

**494 转化的代数**：设正集和 P、负集和 N，`P − N = target` 且 `P + N = total` ⟹ `P = (total+target)/2`——奇偶不整除则无解。**DP 前的等式变形是本题真正的考点**。

## 6. 迁移与连接

- 背包 = 家族 10 的"选择集 + 资源约束"扩维；494 的转化思想 = 把约束先做代数化简
- LIS 的 O(n log n) 内芯 = 家族 4 lowerBound；d 数组思想与家族 5 单调栈同源（维护"档案"而非实况）
- 区间 DP（家族 12）与树形 DP（家族 7 的 124 思想）是 DP 的另外两个维度方向
