# 二叉堆（最小堆）性质的正确性证明

对应代码：`algo/genericheap.go`（`up`、`down`、`Push`、`Pop`、`NewHeapFrom`）。

讨论的问题：堆凭什么保证"根上永远是最小值"，且插入/弹出后这条保证不塌？用不变式方法（同 `infinite-num-set-proof.md` 的套路：先写规格，再写不变式，逐操作归纳）证明五件事：

- **定理 A**：堆序 ⟹ 根是全局最小（"O(1) 找 min"的数学根据）
- **引理 B/C**：`up`/`down` 修复单点破坏后堆序全局恢复
- **定理 D**：高度 = ⌊log₂n⌋ ⟹ Insert/Pop = O(log n)
- **定理 E**：Push/Pop 的完整行为正确性
- **定理 F**：Floyd 建堆正确且 O(n)

---

## 0. 记号与定义

数组 `a[0..n)`，节点下标按完全二叉树**层序编号**，父子由算术给出：

$$
\mathrm{parent}(i) = \lfloor (i-1)/2 \rfloor,\quad
\mathrm{lchild}(i) = 2i+1,\quad
\mathrm{rchild}(i) = 2i+2
$$

（层序编号与父子公式的自洽性：按层归纳即可，每个内部节点的孩子恰为下一层连续两个位置，略。）

**堆序（heap property）**：

$$
\mathrm{HP}(a, n) \;\equiv\; \forall\, j \in [1, n):\;\; a[\mathrm{parent}(j)] \le a[j]
$$

即"每条父子边都满足父 ≤ 子"。注意 HP **只约束竖直方向的边**——兄弟之间、跨子树之间没有任何约束。

多重重申本文用到的两个初等事实：

- **F1（交换不变）**：swap 不改变数组的多重集。
- **F2（传递性）**：$x \le y \wedge y \le z \Rightarrow x \le z$。

---

## 1. 定理 A：根是全局最小元

**命题**：若 $\mathrm{HP}(a,n)$ 成立且 $n \ge 1$，则 $\forall j \in [0,n):\ a[0] \le a[j]$。

**证明**：对 $j$ 强归纳，命题记为 $P(j):\ a[0] \le a[j]$。

- $j = 0$：自反，成立；
- $j > 0$：设 $p = \mathrm{parent}(j) = \lfloor(j-1)/2\rfloor < j$。由 HP（在边 $(j, p)$ 上）得 $a[p] \le a[j]$；由强归纳假设 $P(p)$（$p < j$）得 $a[0] \le a[p]$；由 F2 传递得 $a[0] \le a[j]$。$\blacksquare$

**三个直接推论**（这就是"局部有序、全局无序、min 在根"的精确形式）：

1. **全局半序**：所有元素 $\ge$ 根——全局无序不等于没有全局信息；
2. **兄弟无序**：$a[1]$ 与 $a[2]$（根的左右孩子）可以任意大小关系，HP 不约束。例：$[1, 5, 2]$ 和 $[1, 2, 5]$ 都是合法堆；
3. **min 唯一确定位置**：最小值必在 $a[0]$（O(1) 取 min 的来源）；而**最大值只知在叶子里**（无孩子才无约束），具体在哪一片叶无信息——所以最小堆找 max 要扫全部叶子，O(n)。

## 2. 引理 B：`up` 修复"某位置的值变小了"

**算法**（对应 `genericheap.go` 的 `up`）：

```
up(i):  while i > 0 且 a[i] < a[parent(i)]:
            swap(a[i], a[parent(i)]);  i = parent(i)
```

**前置条件** $Pre_B$：数组原先满足 HP；随后**单个位置** $i$ 的值被替换为 $v$，且 $v \le$ 原值 $a_{old}[i]$。

（两个实例：`Push` 是"长度从 $n-1$ 变 $n$，新位置 $n-1$ 放 $v$"，无孩子、原值视作 $+\infty$；`Update` 后值变小时走 `up` 同理。）

**循环不变式** $Inv_B$（每次循环条件判定前成立，设当前浮动位置为 $i$，位置上的值为 $v$）：

- **B1**：多重集不变（只做过 swap，F1）；
- **B2**：除边 $(i, \mathrm{parent}(i))$ 外，其余所有边均满足 HP；
- **B3**：$v$ 沿途留下的位置都满足 HP（它们现在装的是被换下来的旧值，见归纳步）。

**归纳步**：设本轮条件为真（$i>0$ 且 $v < a[p]$，记 $p = \mathrm{parent}(i)$，$w = a[p]$）。执行 swap 后：位置 $i$ 装 $w$，位置 $p$ 装 $v$。需验证：

- 边 $(c, i)$，$c$ 为 $i$ 的孩子：需 $w \le a[c]$。链条：变更前 HP 给 $a_{old}[i] \le a[c]$ 与 $w = a_{old}[p] \le a_{old}[i]$，故 $w \le a_{old}[i] \le a[c]$ ✓
- 边 $(c_2, p)$，$c_2$ 为 $p$ 的另一孩子：变更前 HP 给 $w \le a[c_2]$，而新值 $v < w \le a[c_2]$ ✓
- 其余边：数值未动 ✓

于是唯一的"未证边"上移为 $(p, \mathrm{parent}(p))$，$Inv_B$ 以新浮动位置 $p$ 保持。

**终止性**：父指标 $(i-1)/2 < i$ 严格递减、下界 0，循环至多执行 $h$（树高）次。

**出口**：两种退出方式都给出全局 HP：$i = 0$（根无父边，B2 即全局 HP）；或 $v \ge a[p]$（该边也成立，B2 升级为全局 HP）。$\blacksquare$

## 3. 引理 C：`down` 修复"某位置的值变大了（或被外来值占据）"

**算法**（对应 `down`，返回是否移动过）：

```
down(i):  loop:
              m = i 的现有孩子中最小者的下标（无孩子则退出）
              若 a[m] >= a[i]: 退出
              swap(a[i], a[m]);  i = m
```

**前置条件** $Pre_C$：除"从 $i$ 的孩子指向 $i$ 的边"之外，所有边满足 HP——等价地说：$i$ 的左右子树各自是堆，$i$ 之外的部分不受影响。

（实例：`Pop` 把末元素搬到根后 `down(0)`——原根的两棵子树未动，是堆 ✓；`Update` 值变大走同路。）

**循环不变式** $Inv_C$（设当前下沉位置 $i$，其值为 $v$）：

- **C1**：多重集不变；
- **C2**：除"从 $i$ 的孩子指向 $i$ 的边"外，其余所有边满足 HP；
- **C3**：每层被换上去的旧孩子值，在它的新位置满足 HP（见归纳步）。

**归纳步**：设选中 $m$（$a[m] \le a[c_2]$，另一孩子 $c_2$）且 $a[m] < v$。swap 后：位置 $i$ 装 $w = a[m]$，位置 $m$ 装 $v$。验证：

- 边 $(c_2, i)$：需 $w \le a[c_2]$——由 $m$ 是**较小**孩子的选法直接给出 ✓
- $m$ 的子树挂到了 $v$ 底下：$m$ 的孩子与 $v$ 的边可能违反——这正是 C2 允许的、且唯一允许的未证边，违反点随 $i := m$ 下移 ✓
- 其余边：数值未动 ✓

**终止性**：$m = 2i+1$ 或 $2i+2$ 均 $> i$，下标严格递增、上界 $n$，至多 $h$ 次。

**出口**：$a[m] \ge a[i]$（两个孩子都不小于 $v$，未证边全部成立）或 $i$ 为叶子（无孩子边）——两种情况 C2 都升级为全局 HP。$\blacksquare$

**注意**（`Fix` 的根据）：$Pre_B$ 与 $Pre_C$ 合起来覆盖"值可能变大也可能变小"的任意修改——这正是 `genericheap.go` 中 `Fix` 写成"先 `down`，没动过再 `up`"的原因：两条引理的前置条件互补。

## 4. 定理 D：高度与复杂度

**命题**：$n$ 个节点的完全二叉树高度 $h = \lfloor \log_2 n \rfloor$。

**证明**：第 $0$ 到 $h-1$ 层是满的，共 $2^h - 1$ 个节点；第 $h$ 层至少 1 个、至多 $2^h$ 个。故
$$
2^h \;\le\; n \;\le\; 2^{h+1} - 1 \;<\; 2^{h+1}
\quad\Longrightarrow\quad h = \lfloor \log_2 n \rfloor \qquad \blacksquare
$$

**推论**：`up` 沿父链走、`down` 沿子链走，步数 $\le h$，比较次数 $\le 2h$（`down` 每层比两个孩子）。故：
$$
\text{Push} = O(\log n),\qquad \text{Pop} = O(\log n),\qquad \text{Peek} = O(1)
$$

---

## 5. 定理 E：Push 与 Pop 的完整行为正确性

**规格**（多重集语义）：

- `Push(v)`：堆多重集 $S \mapsto S \uplus \{v\}$；
- `Pop()`：前置 $n \ge 1$；返回值 $= \min S$；$S \mapsto S \setminus \{\min S\}$（去掉一个最小元）。

**Push 的证明**：append 使长度 $n-1 \to n$，新位置 $n-1$ 无孩子、无父边约束冲突，恰为 $Pre_B$ 的"新位置"实例；由引理 B，结束时 HP 全局成立，且由 B1 多重集恰增一个 $v$。∎

**Pop 的证明**：

- **返回值正确**：返回的是旧根 $a[0]$，由定理 A 它是 $\min S$；
- **堆序恢复**：末元素搬到根、长度减一后，根的两棵子树未被动过（各自是堆），其余边未变——即 $Pre_C$ 在 $i = 0$ 成立；由引理 C，结束时 HP 全局成立；
- **多重集正确**：去掉的恰是旧根（一个最小元），由 F1 其余元素仅被 swap 移位。∎

**顺带**：`genericheap.go` 的 `Pop` 在缩容前把槽位写零值，不影响本证明（HP 是关于 $[0, n)$ 的命题），其作用是 GC 语义。

## 6. 定理 F：Floyd 建堆正确且 O(n)

**算法**（对应 `NewHeapFrom`）：

```
for i = ⌊n/2⌋ - 1 downto 0:  down(i)
```

**正确性**（对 $i$ 反向归纳）：不变式：$\forall j > i$，以 $j$ 为根的子树是堆（叶子平凡成立）。

- **归纳步**：处理 $i$ 时，其孩子 $2i+1, 2i+2 > i$，由不变式它们为根的子树是堆——恰为 $Pre_C$ 限制在子树 $i$ 内的版本；由引理 C（论证只涉及子树内部），处理后以 $i$ 为根的子树是堆。
- **终态**：$i = 0$ 处理完，整棵树（以 0 为根）是堆。$\blacksquare$

**成本**：高度为 $k$ 的节点做 `down` 至多 $k$ 次交换；高度为 $k$ 的节点至多 $\lceil n/2^{k+1} \rceil$ 个（第 $k$ 层以上是满二叉树，叶层至多占一半再逐层折半）。总交换次数：

$$
\sum_{k=0}^{h} \left\lceil \frac{n}{2^{k+1}} \right\rceil \cdot k
\;\le\; n \sum_{k=0}^{\infty} \frac{k}{2^{k+1}} + O(h)
\;=\; n \cdot 1 + O(\log n) \;=\; O(n)
$$

（用到 $\sum_{k \ge 0} k/2^{k+1} = 1$。）**线性建堆成立**，优于逐个 `Push` 的 $O(n \log n)$。$\blacksquare$

---

## 7. 小结

| 想要的性质 | 证明出处 | 关键机制 |
|---|---|---|
| min 在根，O(1) 取 | 定理 A | 沿祖先链强归纳 + 传递性 |
| 值变小 → up 修复 | 引理 B | 不变式："唯一未证边"随浮动位置移动 |
| 值变大 → down 修复 | 引理 C | 同上，"选较小孩子"保证换上去的值压得住另一边 |
| Insert/Pop O(log n) | 定理 D | 完全二叉树高度 ⌊log₂n⌋ |
| Push/Pop 行为正确 | 定理 E | A + B + C 组装 |
| 建堆 O(n) | 定理 F | 反向归纳 + 高度加权求和收敛 |

证明结构与 `infinite-num-set-proof.md` 同构：**规格（第 5 节）→ 不变式（B2/C2 的"唯一未证边"）→ 逐操作归纳 → 组装成主定理**。其中 B2/C2 的"唯一未证边"就是堆版本的 α 桥梁——它把"全局是堆"这个大命题压缩成"只有一条边待证"的小命题，随操作移动，直至消失。
