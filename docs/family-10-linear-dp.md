# 家族 10：线性动态规划 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：方案数 / 最值 / 可行性（"能不能/多少种/最少代价"）+ 子问题重叠
- **原语**：状态五要素（状态/转移/初始化/顺序/答案位置）、一维扫描（Kadane）、不相邻选择（打家劫舍）、环形拆解
- **锚点**：状态定义能一句话说清吗 → 转移是不是自然语言 → 遍历顺序保证依赖先算 → 答案在 dp 表哪个格子
- **失效**：状态空间爆炸（背包容量 × 值域过大）；有后效性（状态需扩维）

## 1. 识别与反识别

**正信号**：最优/计数 + 可分解为子问题；复杂度反推排除贪心（局部最优不保证全局）。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 53 最大子数组和 vs 121 买卖股票 | 53 是 Kadane（以 i 结尾的最优）；121 更简单——一遍维护"历史最低"就是贪心。**先问贪心够不够，不够再 DP** |
| 198 打家劫舍 vs 152 乘积最大子数组 | 同是一维扫描：198 的选择是"偷/不偷"（依赖前两家）；152 的选择是"继承/另起"且负负得正——转移方程里藏着乘法符号陷阱 |
| DP vs 记忆化搜索 | 转移是"从谁推来"清晰 → 递推表；搜索方向自然（如从右往左的博弈）→ 记忆化。同一物两种皮 |

## 2. 入门讲解

DP 的全部功夫在**状态定义**——定义好了，转移方程是自然语言（家族 10 核心解法原话）。标准流程五要素（8020 的过关标准）：

**状态 / 转移 / 初始化 / 遍历顺序 / 答案位置**

以 198 打家劫舍为例走完五要素：

- 状态：`dp[i]` = 考虑前 i 家能偷到的最大值
- 转移：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`（不偷这家 / 偷这家则前一家不能偷）
- 初始化：`dp[0] = 0, dp[1] = nums[0]`
- 顺序：i 从小到大（依赖先于使用）
- 答案：`dp[n]`

**Kadane（53）——一维扫描的原型**：状态定义为"**以 i 结尾**"的最大子数组和（不是"前 i 个"——这个定义差一档，转移写不出来）。`dp[i] = max(dp[i-1] + a[i], a[i])`（继承或另起），答案是 `max(dp)` 而非 `dp[n]`——**"以 i 结尾"型状态的答案位置在整表最大值**，这是第一个易错点。

**213 环形拆解**：首尾相连 ⟹ 首尾不能同偷 ⟹ 拆成两个线性子问题（去掉尾 / 去掉头）各跑一遍 198 取大。**环 → 破环成链的分类讨论**是环形 DP 的通用起手。

**64 最小路径和**：二维表 `dp[i][j] = min(上, 左) + a[i][j]`——网格只有右/下两种来向，依赖关系自动定遍历顺序。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 状态五要素 | 状态/转移/初始化/顺序/答案 | 最优子结构 + 无后效性 | 状态数 × 转移代价 |
| "以 i 结尾"型 | `dp[i]` 挂在 i 上，答案取 `max(dp)` | 连续段类问题 | O(n) |
| 不相邻选择 | `max(dp[i-1], dp[i-2]+v)` | 相邻互斥 | O(n) |
| 环形拆链 | 分类去首/去尾各跑一遍 | 环上约束可拆 | O(n) |
| 网格路径 | `dp[i][j] = min(上,左) + c` | 只能右/下移动 | O(mn) |
| 滚动数组 | 只留最近 k 行/列 | 依赖深度 ≤ k | 空间 O(k) |

## 4. 思维锚点（含经典翻车模式，本族未开垦）

| # | 锚点问句 | 经典翻车（待本仓库实证） |
|---|---|---|
| 1 | **状态定义一句话说得清吗？** | `dp[i]` 定义含糊（"前 i 个某种最优"说不下去）→ 转移写不出 → 状态选错返工。**说不出状态的 DP 不是 DP** |
| 2 | **答案在哪个格子？** | "以 i 结尾"型答案取 `max(dp)` 不是 `dp[n]`；198 型答案恰在 `dp[n]`——五要素的最后一格最容易漏 |
| 3 | **初始化的哨兵对吗？** | 求最小初始化为 0（应为 +∞）、空串空数组边界——初始化是转移的基例，错一个全表歪 |
| 4 | **遍历顺序保证依赖先算？** | 二维表从 (0,0) 起、依赖"上和左"却按列优先填错向——顺序由依赖图拓扑决定 |
| 5 | **有后效性吗？** | 状态里缺维度（如 152 忘记负数翻转最大最小）→ 当前定义下未来影响过去 → 加维（同时维护 max/min） |

## 5. 数学形式化

**最优子结构定理**。

- **命题**：若 `dp` 的定义满足"全局最优解包含子问题的最优解"，则按转移方程填表得全局最优
- **证明**：反证——若某子问题取非最优，替换为最优则整体不劣，与全局最优矛盾；归纳到基例 ∎
- **假设**：**无后效性**（状态确定后，未来与到达该状态的路径无关）
- **反例**：含环的依赖（状态互相推出）→ 拓扑序不存在，填表死循环或错值；152 的负数使"仅维护最大"产生后效（负×负翻转为最大）→ 状态必须同时带 min

**Kadane 不变量**：归纳可证 `dp[i]` 恰为以 i 结尾的最大子数组和——基例显然；归纳步中"继承或另起"取 max 覆盖了以 i 结尾子数组的两种形态（扩展前缀 / 自己单开）∎。前缀和视角的等价式：`dp[i] = a[i] + max(0, dp[i-1])` = 当前前缀和减去历史最小前缀和——**Kadane 就是家族 3 前缀差的滑动版**。

**DP 与贪心的分界**：贪心 = 每步局部最优且可交换论证全局最优（家族 13）；DP = 枚举所有子问题选择取最优。**贪心是 DP 的可压缩特例**——当转移的 max 恒被同一分支赢时，DP 退化为贪心。

## 6. 迁移与连接

- Kadane 与家族 3 前缀和互为视角（§5）；152 是 Kadane 的乘法变体
- 背包/子序列 DP（家族 11）是本族加入"容量/双串"维度后的形态
- 5/32（家族 12）= 区间 DP：状态从"前缀"变为"区间 [i,j]"，遍历按区间长度
