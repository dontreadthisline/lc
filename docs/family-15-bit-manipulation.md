# 家族 15：位运算 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：只出现一次/成对抵消；数 1 的个数；二进制计数/构造；不允许额外空间的标记
- **原语**：异或消消乐（自反+结合）、`x & (x-1)` 消最低位 1、`x & -x` 取最低位 1、逐位计数
- **锚点**：偶数次出现能抵消吗（异或域）→ 要位独立还是整体（按位拆 vs 整数看）→ 溢出与符号位 → 0 的边界
- **失效**：次数为奇数>1 的抵消（3 次出现 → 按位计数 mod 3）；需要十进制语义的问题

## 1. 识别与反识别

**正信号**："其他元素都出现两次、只有一个出现一次"；"1 的个数"；"二进制下……"。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 136 只出现一次 vs 137 出现一次II（题单外） | 全体成对 → 异或一次搞定；**三次出现** → 异或域失效，改按位计数 mod 3（`cnt[i] % 3`）——抵消的模数决定武器 |
| 191 位1的个数 vs 338 比特位计数 | 191 单个数：`x&(x-1)` 逐个消；338 全数组：DP——`bits[i] = bits[i>>1] + (i&1)`，**位计数本身也是 DP**（家族 10 客串） |
| 268 丢失的数字 vs 排序找缺 | 值域 0..n 恰缺一 → 异或全员或求和相减两条 O(n) O(1) 路——数学抵消型的入门 |

## 2. 入门讲解

**异或消消乐（136）**：异或两条性质打天下——**自反**（`a^a = 0`，成对抵消）与**交换结合**（顺序无关）。全数组异或一遍，成对的全消光，剩下孤零零那个：

```
res = 0; for x in nums: res ^= x
```

**为什么抵消是合法的**：把每个整数看成一排开关（二进制位），异或 = 按位"不同为 1"。同一开关被按偶数次 = 回到原状。**成对出现 + 异或 ⟺ 偶数次按开关全复位**。

**`x & (x-1)`（191）**：x−1 把最低位的 1 借位拆掉，与运算后恰好消去那个 1——每次消一个，消几次就是几个 1。比逐位移快"1 的个数"步。

**`x & -x`**：补码的性质送你"只保留最低位 1"（lowbit）——树状数组的基石（家族 3 的失效方向），也是按位分组的利器。

**338 的递推**：`bits[i] = bits[i & (i-1)] + 1`（消掉最低 1 后的答案 +1）或 `bits[i] = bits[i>>1] + (i&1)`（右移一位是它的子问题）——**位计数不是暴力题，是小 DP**。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 异或抵消 | `res ^= x` 全员 | 出现次数为偶 | O(n) |
| 消最低 1 | `x &= x-1`（计数循环） | — | O(popcount) |
| 取最低 1 | `x & -x`（lowbit） | 补码表示 | O(1) |
| 按位计数 DP | `bits[i] = bits[i>>1] + (i&1)` | 值域连续 | O(n) |
| mod-k 抵消 | 逐位计数 `% k` | 出现 k 次型 | O(32n) |
| 异或前缀 | `pre[i+1] = pre[i]^a[i]`（家族 3 同构） | 区间异或查询 | O(n) 预处理 |

## 4. 思维锚点（含经典翻车模式，本族未开垦）

| # | 锚点问句 | 经典翻车（待本仓库实证） |
|---|---|---|
| 1 | **抵消的模数是多少？** | 三次出现用异或：异或域里 3 次出现留下"一次"的痕迹但和真正的一次混在一起——**按位 mod 3** 才分得开 |
| 2 | **按位独立看还是整体看？** | 整体异或对"每一位互相独立"的问题有效；位间有进位/数值语义时（求和、比较大小）异或失能 |
| 3 | **负数的补码处理了吗？** | `-x` 的位形依赖补码；`x>>1` 算术右移带符号——移位用无符号类型最稳 |
| 4 | **0 的边界？** | `x&(x-1)` 循环对 x=0 直接退出；lowbit(0) = 0 无意义——位运算的基例经常是 0 |
| 5 | **优先级加括号了吗？** | `x & 1 == 1` 在 Go 里解析成 `x & (1==1)`？——Go 强制括号救了你，但移植到 C 系语言就是经典坑 |

## 5. 数学形式化

**异或的代数结构**。

- **命题**：固定宽度的整数在异或下构成交换群：结合、交换、单位元 0、每个元素自逆（`a^a=0`）
- **推论**：$\bigoplus_{x \in S} x$ 只依赖每个值出现次数的奇偶性——偶者消尽。136 的正确性是该推论的直接特例 ∎
- **几何视角**：整数 = $\mathbb{Z}_2^k$ 向量（k 位开关），异或 = 向量加法——"消消乐"就是线代里的模 2 求和
- **反例（假设违规）**：出现次数为 3（奇但非 1）：$\bigoplus$ 留下痕迹但无法与真单次区分——改用每位计数的 mod 3（每位独立解 $\mathbb{Z}_3$ 方程）

**`x & (x-1)` 定理**。

- **命题**：`x & (x-1)` 恰消去 x 的最低位 1
- **证明**：设最低 1 在第 k 位，`x = ...1 0...0`（k 位起），`x-1 = ...0 1...1`（借位拆 k）——高位不变、第 k 位清零、低位全 1 与原 0 相与为 0 ∎
- **推论**：循环计数 = popcount 的逐 1 前进，步数恰为 1 的个数

**338 递推的正确性**：`i>>1` 是 `i` 去掉末位的子问题（归纳假设覆盖），末位由 `i&1` 补——状态定义"i 的 1 的个数"满足最优子结构（此处是平凡计数结构）∎。

## 6. 迁移与连接

- 异或前缀 = 家族 3 前缀和在 $\mathbb{Z}_2^k$ 群上的同构（区间异或 = 前缀异或相"减"，减法即加法）
- lowbit = 树状数组（家族 3 失效方向的钥匙）的基石原语
- 状态压缩 DP（题单外）= 子集的位掩码表示——位运算是它的底层语言
