# 家族 17：矩阵与模拟 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：顺时针/螺旋遍历；原地旋转/置零；按层收缩；二维结构判定
- **原语**：边界收缩不变量（上下左右四指针）、转置+翻转（旋转 90°）、首行首列做标记（原地置零）、锚点步进法（240 右上角）
- **锚点**：边界怎么收缩（谁先谁后）→ 原地操作的暂存区在哪 → 旋转分解成哪两个变换 → 单调性结构上能不能双指针
- **失效**：需要 O(1) 空间又要保持信息 → 找矩阵自身的空位当暂存（标记法）

## 1. 识别与反识别

**正信号**：m×n 矩阵 + 按圈遍历/原地变换/逐层处理。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 54 螺旋 vs 48 旋转 | 螺旋 = **读**的顺序游戏（边界收缩）；旋转 = **写**的位置变换（转置+翻转）——读题 vs 写题 |
| 73 矩阵置零 vs 普通标记法 | 要求 O(1) 空间 → 标记**寄存在矩阵自己的首行首列**（首行/首列自身的命运先用两个标量记）——空间极限逼出自存储 |
| 240 搜索二维矩阵II vs 74 搜索二维矩阵 | 74 行间也递增 → 拉直成一维二分（家族 4 客串）；240 只行列各自递增 → **右上角锚点步进**（本族双指针形态） |

## 2. 入门讲解

**螺旋遍历（54）**：四边界 `top/bottom/left/right` 收缩。不变量：**未读区域 = [top..bottom] × [left..right]**。每轮按"上边从左到右 → 右边从上到下 → 下边从右到左（需 top<bottom）→ 左边从下到上（需 left<right）"走一圈，四边界各收缩一格。**后两步的条件判断是唯一考点**——单行/单列残留时反向走会重复读。

**旋转 90°（48）**：分解为两个简单变换的复合——**先转置（沿主对角线镜像），再左右翻转**。位置映射的验证：`(i,j) →(转置)→ (j,i) →(翻列)→ (j, n-1-i)`，恰是顺时针 90° 的像 ∎（见 §5）。原地交换两两进行，O(1) 空间。

**置零（73）**：任何格为 0 → 其所在行、列全清零。朴素用两个集合记行/列。O(1) 版：**首行首列当集合用**——`matrix[0][j]=0` 表示第 j 列要清，`matrix[i][0]=0` 表示第 i 行要清；首行首列自身的命运先用两个布尔记下（鸡生蛋问题：它们既是标记区又是待定区）。

**锚点步进（240）**：行列皆递增的矩阵找 target。从**右上角**出发：当前值 > target → 整列最小都在左……不对，是这一列往下更大，排除**这一列**（左移）；当前值 < target → 这一行往左更小，排除**这一行**（下移）。每步淘汰一整行或列，O(m+n)。**锚点的选择是命门**：左上角（右和下都变大）与右下角（左和上都变小）给不出唯一方向，只有右上/左下两个"单增单减"角可用。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 边界收缩 | top/bottom/left/right 四指针，每轮走一圈缩一格 | 不变量：未读区 = 矩形 | O(mn) |
| 转置+翻转 | `A[i][j]↔A[j][i]` 后每行 reverse | 旋转 90° 的倍数 | O(n²) O(1) 空间 |
| 首行首列标记 | 标记寄存 + 两个标量记首行/列命运 | O(1) 空间要求 | O(mn) |
| 锚点步进 | 右上/左下角出发，每步删一行或一列 | 行列均单调 | O(m+n) |
| 拉直二分 | 一维化 + lowerBound | 行间也单调（74 型） | O(log mn) |

## 4. 思维锚点（含经典翻车模式，本族未开垦）

| # | 锚点问句 | 经典翻车（待本仓库实证） |
|---|---|---|
| 1 | **反向那两步的条件写了吗？** | 螺旋单行/单列残留：下边从右到左、左边从下到上若不加 `top<bottom`/`left<right` 判断，元素被重复收 |
| 2 | **旋转分解的两步顺序对吗？** | 先翻转后转置 = 逆时针 90°——复合不可交换，映射式验一遍再写码 |
| 3 | **标记区自身谁来看守？** | 73 的首行首列既是标记又是待定：不先记命运再写标记，标记被自身清零污染 |
| 4 | **锚点选在哪个角？** | 左上角出发：右变大、下也变大——两个方向都可能，无法步进；**单增单减角才可用** |
| 5 | **边界收缩的循环终止条件？** | `top > bottom || left > right` 与 `>=` 差一位：奇偶尺寸下多走或漏走一圈 |

## 5. 数学形式化

**旋转的分解定理**。

- **命题**：顺时针 90° 旋转 = 转置 ∘ 左右翻转
- **证明**：追踪单点映射。转置 $(i,j) \mapsto (j,i)$；翻列 $(j,i) \mapsto (j, n{-}1{-}i)$；复合 $(i,j) \mapsto (j, n{-}1{-}i)$——与顺时针 90° 的几何定义逐点一致 ∎
- **反例（顺序交换）**：翻列 ∘ 转置 $(i,j) \mapsto (n{-}1{-}j, i)$ = 逆时针 90°——变换复合不可交换的活例

**锚点步进的淘汰正确性**。

- **命题**（240）：从右上角 (r,c) 出发，`A[r][c] > t ⟹ 第 c 列无 t`；`A[r][c] < t ⟺ 第 r 行无 t`
- **证明**：列递增 ⟹ A[r][c] 是该列已见最小（r 上方已被淘汰），它已 > t 则下方更大；行递增 ⟹ A[r][c] 是该行最大（c 右侧已淘汰），它已 < t 则左侧更小 ∎
- **假设**：行、列各自非降
- **反例（假设违规）**：74 型矩阵行间递增时可拉直二分更快；完全无序矩阵锚点步进失效（退化 O(mn) 暴扫）

**螺旋不变量**：四边界界定的矩形 = 尚未访问的子矩阵。每圈后矩形严格缩小（四边界各 +1/−1），至多 min(m,n)/2 圈终止 ∎。

## 6. 迁移与连接

- 240 的锚点步进 = 家族 2 双指针在**单调二维结构**上的投影（每步淘汰一行/列 ↔ 窗口淘汰非法起点）
- 边界收缩与家族 12 区间 DP 的"区间收缩"同是**不变量驱动的过程设计**
- 标记法 O(1) 空间思想 = 家族 16"结构自带暂存区"的矩阵版
