# 家族 2：双指针与滑动窗口 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：连续段上的最值/长度/计数；窗口合法性只依赖窗口内容；n ≥ 10⁵
- **原语**：流派 A（最长：不合法才缩）、流派 B（最短：合法才缩）、`atMost(g)`（计数原语）、双指针三模式（间距恒定/增长/追赶）
- **锚点**：方向无歧义吗（预算 vs 等值）→ 答案记在哪/何时 → 计数题化 atMore → 收缩永远 `i <= j` → 开闭和基点从题面读
- **失效**：元素可负 → 一切崩塌（恰好型去家族 3，不等式计数去树状数组）

## 1. 识别与反识别

**正信号**：子串/子数组 + 最长/最短/个数；"至多 K 种/至多 k 次"这类预算词。

**数据范围是最硬的信号**：n ≥ 10⁵ + 连续段 → O(n) → 候选只剩滑窗/哈希/前缀和三族，再用负元素与否分拣。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 904 水果成篮 vs 395 至少K个重复字符 | 904 "种类 ≤ 2"是**预算**（收缩可修复）；395 "每种 ≥ k"是**等值**（次数不够只能等右指针）——前者滑窗直解，后者必须种数枚举绕道 |
| 930 和相同的二元子数组 vs 560 和为K | "恰好 = goal"且元素非负 → atMost 相减可用；元素含负 → 单调性没了，atMost 无定义，只能家族 3 |
| 209 长度最小 vs 713 乘积小于K | 同一骨架的两个流派：B 求最短（合法才缩）、A 求计数（不合法才缩）——判定方向相反 |

## 2. 入门讲解：从 003 到两流派

003（无重复字符最长子串）暴力：枚举所有子串判合法，O(n²)。观察：固定右端 j 后，最左合法起点 i(j) 关于 j **单调不减**——j 前进，i 要么不动要么右移，绝不回退。i、j 各走一遍，O(n)。

骨架就此定型（`lc/sliding_window_template.go`）：

```
流派 A（最长合法窗口）：扩 → 不合法才缩 → 合法时记答案（3、424、904）
流派 B（最短合法窗口）：扩 → 合法才缩找更短 → 缩中记答案（209、76）
```

**计数扩展（713/930/992）**：窗口还能数个数——缩到合法后 `res += j−i+1`，数的是"以 j 结尾的合法起点数"。由此长出原语 `atMost(g)` 和三条恒等式（§5）。

**双指针三模式**（家族 6 回响）：间距**恒定**（019：倒数坐标由间距携带）、**线性增长**（876：fast 到尾时间距≈l/2，slow 在中点）、**环内追赶**（141：每步差 1，环长步内必遇）。同一个思想：绝对位置拿不到，用相对位置编码信息。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 流派 A 最长 | 扩 j；`for i<=j && 非法 {缩}`；记 `max(j-i+1)` | 合法性对收缩**单调可修复**（预算型） | O(n) |
| 流派 B 最短 | 扩 j；`for i<=j && 合法 {记 min; 缩}` | 合法性对扩张封闭 | O(n) |
| `atMost(g)` | 元素非负数组、阈值 g → 和 ≤ g 的子数组数；缩到 `sum ≤ g` 后 `res += j-i+1` | 元素非负（支配性）；和为整数（偏移恒等式） | O(n) |
| 种数预算窗 | `for len(m) > t {缩}`，记录条件另行 | 允许种数做预算；t ∈ 小常数域 | O(n·t) |
| 双指针三模式 | 间距恒定 / 2:1 增长 / 环内追赶 | 各自见锚点 5 | O(n) |

**atMost 恒等式族**（计数题的代数层）：`恰好g = atMost(g) − atMost(g−1)`；`>g = T − atMost(g)`，T = n(n+1)/2；整数域 `<g = atMost(g−1)`。952/992 型"恰好 K 种"= 恒等式 + 种数预算窗。

## 5. 数学形式化

**流派 A 三断言**（以 `res += j−i+1` 为例，i 为收缩后左界）：

1. **整窗合法**：退出谓词即合法（或空窗贡献 0）
2. **支配性**：$s \in [i,j] \Rightarrow P(s,j) \le P(i,j) < k$——度量对去左单调不增
3. **永久非法**：$s' < i$ 被踢出时刻量 ≥ k，此后只增不减

- **贡献计数定理**：按右端点划分子数组族（两两不交），断言 2+3 ⟹ 以 j 为右端的合法起点集恰为 $\{i..j\}$，每轮计入 j−i+1 与该类基数相等，求和即总数 ∎（完整推导与 2 万组对拍见 713 注释与 `TestNumSubarrayProductLessThanKBruteCrossCheck`）
- **假设**：断言 2 的"元素非负"（和）/“元素 ≥ 1"（乘积，0 毒化）；断言 3 的"度量只增不减"
- **反例**：`nums=[0,1000], k=500`——窗口乘积 0 合法，子窗 `[1000]` 非法，支配性破产，`res += j−i+1` 多数；含负元素时断言 3 同样破产（被踢起点可复活：`[3,−2]` 的起点 0 在 j=1 时和为 1 起死回生）

**atMost 恒等式**。

- **命题**：整数值域上 $\#\{=g\} = \#\{\le g\} - \#\{\le g{-}1\}$，$\#\{>g\} = T - \#\{\le g\}$
- **证明**：≤/> 是完备划分（第二式）；整数下 $\{<g\} = \{\le g{-}1\}$（第一式的偏移）∎
- **假设**：和为整数（实数域第一式失效）；atMost 本身的非负前置（见上）
- **反例**：实数权重下 `恰好 5.0 ≠ atMost(5.0) − atMost(4.0)`

**395 的种数枚举定理**。

- **命题**："每种字符 ≥ k"对收缩不单调；固定允许种数 t 后收缩条件 `total > t`（预算型）单调成立，原条件降级为记录条件 `less == 0`；任何最优解的种数 $t^* \in [1,26]$，枚举不漏解
- **证明**：窗口种数有限且 ≤ 字母表大小；对每个 t 用流派 A 三断言 ∎
- **假设**：字母表大小是常数（26）；字符可数
- **反例**：值域无限（如任意整数做"种类"）时 t 枚举失效，需离散化

**maxCnt 只增不减的正确性**（424）：res 只在窗口**创新高**时更新，创新高时 maxCnt 必然新鲜（新高由新元素贡献）——允许 maxCnt 过期不是 bug，是定理的一部分。

## 6. 迁移与连接

- 恰好型 + 含负元素 → 家族 3 查账（560/974）；非负域两族通吃时优先滑窗（O(1) 空间）
- 992（恰好 K 个不同整数，题单外）= atMost 恒等式 + 种数预算窗，两个已学件的拼装
- 定长窗口（438）= 无收缩退化形态；固定 K 的中位数/最值窗口 → 双端队列/堆（家族 5/14）
