# 家族 8：BFS 与网格 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：无权图/网格的最短步数、最少分钟、层扩散、连通块计数；多源同时开始
- **原语**：单源 BFS（队列+visited）、多源 BFS（全部源先入队）、flood fill（DFS/BFS 染色）、按层快照
- **锚点**：队列不变量（当前层剩余+下层已入）→ visited 在入队时标记 → 层边界怎么记 → 越界/障碍判定先于入队
- **失效**：带权最短路 → Dijkstra（堆，家族 14 连接）；深递归 flood fill 有栈深风险

## 1. 识别与反识别

**正信号**：网格四方向移动求最少步数；"每分钟同时腐烂/扩散"；数岛屿；被包围区域填充。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 200 岛屿数量 vs 994 腐烂橘子 | 只要**连通块计数** → flood fill（DFS 即可）；要**最短时间** → 必须层序（BFS 的层号 = 分钟数） |
| 994 腐烂橘子 vs 127 单词接龙 | 同是多源/单源最短扩散：994 的图是隐式网格（四邻居），127 是隐式词图（逐位变异）——**先想清楚邻居函数**，其余同骨架 |
| BFS vs DFS 选型 | 求"能不能到达/数块"两者都行（DFS 更省代码）；求"最少几步"只有 BFS |

## 2. 入门讲解

**为什么 BFS 天然最短**：队列按"离起点的距离"分层——第 k 层的节点距离恰为 k。第一波到达终点的层号就是最短步数。这个性质的成立**依赖边权全 1**（见 §5 定理与反例）。

**单源骨架**：

```
queue = [起点]; visited[起点] = true; 层号 = 0
while queue 非空:
    快照当前层大小 sz = len(queue)      ← 层边界
    for _ in range(sz):                 ← 恰好消费一整层
        u = 出队; 若 u 是终点 → 返回层号
        for v in 邻居(u):
            if 合法(v) && !visited[v]: visited[v] = true; 入队 v
    层号++
return 不存在路径
```

**多源 BFS（994）**：把所有腐烂橘子**在第 0 层一起入队**——"多源最短"等价于"虚拟超级源点连零边到各源"，代码上就是初始化多塞几个起点，其余一字不改。

**flood fill（200/130/695）**：不记层号、只染色的退化 BFS/DFS——visited 就用原网格改标记（'1'→'0'），数启动次数 = 连通块个数。

**127 单词接龙的关键**：图是隐式的——邻居 = 逐位换字母且在词典中。构建显式邻接表 O(L·n·26) vs 每次现算邻居，选择影响复杂度。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 单源 BFS | 起点 → 各点最短层数 | 边权全 1 | O(V+E) |
| 多源 BFS | 源集合第 0 层齐入队 | 同上 | O(V+E) |
| 按层快照 | `sz := len(q)` 消费一整层 | 需要层号/每层清单 | O(V+E) |
| flood fill | 起点 + 染色函数 | 只问连通不问距离 | O(网格) |
| 隐式图邻居函数 | 坐标→四邻居 / 单词→逐位变异集 | 邻居可 O(度) 枚举 | 依题 |

## 4. 思维锚点（本族未开垦，列经典翻车模式待实战填充）

| # | 锚点问句 | 经典翻车（待本仓库实证） |
|---|---|---|
| 1 | **visited 在入队时还是出队时标记？** | 出队时标记：同一节点被同层多个前驱重复入队，队列爆炸——**入队即标记**是纪律 |
| 2 | **层边界怎么记？** | 不做层快照、只 `len(queue)` 乱判：层号和队列长度混在一起算错步数——`sz := len(q)` 先抄下来 |
| 3 | **越界和障碍判在入队前了吗？** | 先入队后检查：出队才发现非法，visited 已污染 |
| 4 | **多源的"第 0 层"齐了吗？** | 源逐个跑单源再取 max：错——多源同时扩散是"最早被任一源到达"，必须同层起跑 |
| 5 | **起点自身是终点吗？** | 起点即终点的 0 步边界，循环结构常把它漏成 1 步 |

## 5. 数学形式化

**BFS 最短路定理**。

- **命题**：边权全 1 的图上，BFS 首达某点的层数 = 其最短距离
- **证明**：队列距离不变量——任意时刻队列中的元素距离构成非降序列且首尾差 ≤ 1（归纳：入队者的距离 = 出队者 + 1，继承有序性）；归纳可得第 k 层恰含所有距离为 k 的节点 ∎
- **假设**：边权全 1
- **反例**：含 0 权边 → 层序与距离脱钩；含正权边 → Dijkstra（按"当前最短估计"取队首，堆维护——家族 14 的堆角色之一）；含负权 → Bellman-Ford 域

**多源 BFS 的归约定理**：多源最短 = 加虚拟超级源 S、S 到各源连 0 边后的单源 BFS——层序不变（0 边不改变距离分层）。代码实现即"初始化全入队"∎。

**网格到图的映射**：m×n 网格 ↔ V = 合法格点、E = 四邻接——flood fill 的连通块计数 = 图的连通分量数，DFS 每启动一次恰覆盖一个分量（按启动归纳）∎。

## 6. 迁移与连接

- 队列 + 层快照 = 家族 7 的层序遍历（102）在网格上的推广
- 优先队列替换 FIFO 队列 = Dijkstra（家族 14 堆角色"按序取最小"）
- 拓扑排序（依赖类题，题单外）= DAG 上的 BFS 变体（入度驱动）

## 7. 深挖篇：多源 BFS 与层语义（含 994/127 实证翻车）

### 7.1 本仓库实证翻车

**994 腐烂的橘子（两处，均已修复）**：
1. 新感染的橘子 `grid[r1][c1] = 2` 标记了但**没入队**——它没接棒，BFS 只活一层，cnt 对不上账返回 -1
2. `minute += 1` 无条件执行——最后一轮只是清空队列、没有感染发生，`[[2]]` 返回 1 而非 0。修法：`var rotted bool` 层内标记，**有真实感染才计时**
3. 对账：`cnt`（感染数）与 `fresh`（初始新鲜数）不等 → -1（不可达检查）

**127 单词接龙（两处，均已修复）**：
1. `cnt` 数的是边数（扩散轮数），题目要**单词数** = 边数+1——`cnt := 1` 起算（beginWord 入场即第 1 个）
2. `goto ret` 把"找到"与"没找到"接到同一出口——无路径时 fall through 返回了 cnt=1 而非 0。**两条路两个 return，永远不要合并成功与失败出口**

### 7.2 多源 BFS = 超级源归约（为什么只改初始化）

```
虚拟节点 S --零长边--> 每个源 s1..sk
在扩展图上从 S 做单源 BFS 的第一层扩散 = "把所有源入队"
⟹ 多源 BFS 与单源 BFS 逐帧相同, 只是省掉了 S 本身
答案语义: 每点的时刻 = min over sources of dist(si, v) —— 层序保证首达即最短
复杂度 O(mn): 合起来的第 0 层, 不是跑 k 遍单源(O(k·mn))
```

### 7.3 层语义的操作细节（层快照）

```
for len(queue) > 0 {
    snapshot := len(queue)          // 进入时求值一次 = 层边界
    for range snapshot { 出队; 扩散; 入队 }
    if 本层有真实推进 { 计数/计时 }    // 994 的 rotted
}
```
错误形态对照：无层快照 → 全部同层（距离信息丢失）；层内无条件计数 → 空转轮虚计（`[[2]]` 返 1）。

### 7.4 BFS vs DFS 的分界（决策表）

| 问题 | 工具 | 原因 |
|---|---|---|
| 无权图最短步数（994/127）| BFS 层序 | 层号 = 距离，首达即最短 |
| 存在性判定（静态图）| DFS + 永久 visited | 找到即收工，失败可缓存（墓碑清白引理，见 family-09 §7.4）|
| 存在性判定（动态图，如 79）| DFS + 随栈 visited | 图随栈变，失败不能缓存 |
| 枚举所有路径 | DFS + 撤销 | 每条路径亲自走 |

**visited 标记时机**：入队时标记（不是出队时）——否则同一节点被重复入队，队列爆炸。本项目 NumIslandsBFS 的注释"入队就标访问保险一些"说的就是它。

### 7.5 操作清单

1. 多源题先问"时刻 = 到最近源的距离"是否成立 → 成立直接全部入队
2. 计时的三个伴随物：层快照 / 本层推进标记 / 终了对账（-1 检查）
3. 返回"个数/数目"还是"步数/长度"——数点还是数边，写 cnt 前先答这道题
4. 成功与失败的出口物理分开（127 的 goto 事故）
