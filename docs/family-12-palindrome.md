# 家族 12：回文专题 —— 专题讲解

## 0. 速查卡（复习用）

- **信号**：最长回文子串/子序列、回文切分、括号配对极值
- **原语**：中心扩展（2n−1 个中心）、区间 DP（P[i][j] 依赖 P[i+1][j−1]）、Manacher（题单外，O(n) 进阶）
- **锚点**：中心是字符还是缝隙（奇偶）→ 区间 DP 按长度遍历了吗 → 子串 vs 子序列（不连续可跳）→ 答案记长度还是记切点
- **失效**：超长串 + 多次查询 → Manacher/回文自动机（面试低频）

## 1. 识别与反识别

**正信号**：题面出现"回文"二字基本就锁定本族（5 最长回文子串、131 回文切分、32 括号最长有效）。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 5 最长回文**子串** vs 516 最长回文**子序列**（题单外） | 子串连续 → 中心扩展/区间 DP 的 P 恰为"两端相等且内部回文"；子序列可跳 → 区间 DP 转移多一个"丢首/丢尾"分支——**连续性决定转移形态** |
| 5 vs 131 回文切分 | 5 求最长 → 单值 DP；131 列所有切法 → 回溯 + 回文判定预处理（家族 9 + 本族 P 表做内芯） |
| 32 最长有效括号 vs 5 | 32 不是回文是**配对嵌套**——栈/DP 双解，别被"对称"骗进本族 |

## 2. 入门讲解

**中心扩展（5）**：回文有一个对称中心——中心是字符（奇长）或字符间缝隙（偶长），共 **2n−1 个**中心。从每个中心向两侧扩张到失配为止，全程 O(n²)、空间 O(1)。

```
for c in 0..2n-2:            # 中心：n 个字符 + n-1 个缝隙
    l, r = c//2, (c+1)//2    # 缝隙中心的左右起手不同
    while l >= 0 && r < n && s[l] == s[r]: l--, r++
```

**区间 DP（P 表）**：`P[i][j] = s[i..j] 是否回文`，转移 `P[i][j] = (s[i]==s[j]) && P[i+1][j-1]`。**按区间长度从小到大遍历**——内层区间必须先算好（长度是"阶段"，短区间是长区间的子问题）。这张 P 表是 131 回文切分的免费预处理。

**括号的错位警示（32）**：最长有效括号属于"嵌套配对"不属于回文——栈解（弹栈结算长度）或 DP 解（以 i 结尾的有效长度跳转）都是别的家族骨架。**对称 ≠ 回文**。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 中心扩展 | 每中心向两侧扩到失配 | 求极值、允许 O(n²) | O(n²) / O(1) 空间 |
| 回文判定 P 表 | `P[i][j] = eq && P[i+1][j-1]`，按长度遍历 | 需要**反复**判定回文 | O(n²) 预处理 O(1) 查 |
| 回文子序列 DP | `dp[i][j] = max(扩/丢首/丢尾)` 三分支 | 子序列可跳 | O(n²) |
| 切分 DP | `dp[j] = min(dp[i-1]+1)`，i..j 回文 | P 表先备 | O(n²) |

## 5. 数学形式化

**中心完备性定理**。

- **命题**：任何回文子串恰有一个中心（字符或缝隙），中心总数 2n−1
- **证明**：回文 = 关于某点镜像相等的串；奇长串中心在中位字符，偶长串中心在中间缝隙；由长度奇偶性分类恰穷尽 ∎
- **假设**：串由离散字符构成
- **推论**：枚举中心 + 扩张覆盖所有回文子串，无一遗漏

**区间 DP 的阶段单调性**。

- **命题**：按长度从 2 到 n 遍历填 P 表，每次读到的子表项均已完成
- **证明**：`P[i][j]` 只依赖长度 −2 的 `P[i+1][j-1]`（及长度 1/2 的基例）——阶段（长度）是严格递减的依赖链，拓扑序存在 ∎
- **反例**：按下标 i 先序遍历，`P[i+1][*]` 尚未填——依赖倒挂，读到未初始化值

**子序列 DP 的转移完备性**（516 型）：两端的处置只有三种——都保留（配对成功时收益 +2）、丢左、丢右；任何最优子序列对区间的截断形态必居其一 ∎。

## 6. 迁移与连接

- 区间 DP 是家族 10 的状态从"前缀"换成"区间"的维度迁移——**遍历顺序由依赖拓扑决定**的纪律两族通用
- P 表 = 预处理换查询，家族 3"查表面孔"在布尔域的翻版
- 131 = 本族 P 表 + 家族 9 回溯的标准拼装；32 的栈解回连家族 5
