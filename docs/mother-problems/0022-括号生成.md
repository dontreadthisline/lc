# 22. 括号生成

- 难度：中等
- 标签：字符串、动态规划、回溯、括号序列
- 链接：https://leetcode.cn/problems/generate-parentheses/
- 所属：思维4 搜索与回溯｜角色：母题

---

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的 **括号组合。

**示例 1：**
```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```
**示例 2：**
```
输入：n = 1
输出：["()"]
```
**提示：**

- `1 <= n <= 8`
