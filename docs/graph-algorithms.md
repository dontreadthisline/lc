# 图算法：从遍历到最短路的统一视角

对应代码：`algo/dijkstra.go`（Dijkstra 堆版与朴素版）、`algo/genericheap.go`（泛型堆）、`algo/dijkstra_test.go`（随机交叉验证）。

本文是学习沉淀，按难度阶梯组织：表示 → 遍历 → 拓扑 → 最短路 → 生成树 → 进阶路标。

---

## 0. 总地图：所有图算法共享一个骨架

先把全文的钥匙交出来。DFS、BFS、Dijkstra、SPFA，主循环全是同一个骨架：

```
候选池 := {起点}
for 候选池非空 {
    u := 按某种规则从池中取出一个
    处理 u（标记 / 敲定 / 松弛 / ……）
    把 u 的邻居按需放入候选池
}
```

各家算法只是换了"取出规则"和"处理动作"：

| 算法 | 候选池 | 取出规则 | 处理动作 |
|---|---|---|---|
| DFS | 栈 | 栈顶（LIFO） | 标记访问，递归深入 |
| BFS | 队列 | 队头（FIFO） | 标记访问，层序扩展 |
| Dijkstra | 优先队列 | 距离最小者 | 敲定最终距离，松弛出边 |
| SPFA | 队列（可重入） | 队头（FIFO） | 不敲定，改进就重入队 |

一个关键的分界：**遍历算法里，顺序是实现细节**（DFS 换 BFS，访问集合不变）；**最短路算法里，顺序是算法本体**（顺序 = 距离序 = 正确性来源）。这也是为什么最短路一章反复围绕"出队单调性"展开。

## 1. 地基：图的表示

术语速览：顶点数 $V$、边数 $E$；无向/有向；度（出边数/入边数）。**稀疏**指 $E$ 接近 $V$ 量级（路网约 $E \approx 4V$），**稠密**指 $E$ 接近 $V^2$。这个比例几乎决定所有选型。

### 1.1 三种表示的定价表

| | 邻接表 `[][]Edge` | 邻接矩阵（扁平） | 边列表 `[]Edge` |
|---|---|---|---|
| 空间 | $O(V+E)$ | $O(V^2)$ | $O(E)$ |
| 扫 $u$ 的全部邻居 | $O(\deg u)$ | $O(V)$ | $O(E)$ |
| 查边 $u \to v$ | $O(\deg u)$ | $O(1)$ | $O(E)$ |
| 平行边 | 天然支持 | 存不下（一格一值） | 天然支持 |
| 典型用户 | 遍历型算法（BFS/DFS/Dijkstra） | Floyd、稠密图、频繁查边 | Kruskal、Bellman-Ford |

坐标系是分水岭：矩阵的下标**即含义**（`(u,v)` 定位边，格子只存权值），邻接表的下标只是流水号（`(u,k)` = u 的第 k 条边，终点存在 `To` 字段里）。矩阵省掉 `To` 字段的代价是 $V^2$ 空间和整行扫描。

### 1.2 Go 实现细节

- `[][]T` 是 jagged array：n 次独立分配、两次寻址、行不连续。邻接表恰好需要它的自由度（行长 = 出边数）。
- 真矩阵应该用扁平布局：`flat []T` + `flat[r*n+c]` 寻址，一次分配、缓存连续。按行遍历可切片：`row := flat[r*n : (r+1)*n]`。
- 矩阵的"无边"哨兵不能用 0（零权边合法），用 `MaxInt` 或配套 `[][]bool`。
- 节点是字符串/大整数 ID 时，生产模式是**外层 map 翻译、内层数组干活**：`ids map[string]int` 把任意 ID 稠密化成 $0..n-1$，算法内部清一色 slice。

**一句话**：slice 就是"稠密键的 map"。键稠密就直接用数组，不稠密就先稠密化再用数组。

## 2. 两大遍历：DFS 与 BFS

### 2.1 DFS：一条道走到黑

```
dfs(u):
    visited[u] = true
    for v in adj[u]:
        if !visited[v]: dfs(v)      // 深入
    // 返回即回溯
```

性质：递归栈深度最深 $O(V)$；生成 DFS 树/森林；**不保证按任何"远近"顺序访问**。

核心应用，全部是同一个骨架加一点状态：

- **连通分量**：对每个未访问点跑一次 DFS，次数 = 分量数
- **无向图环检测**：访问到已访问的点，且它不是当前点的父节点 → 有环
- **有向图环检测**：三色标记。白（未访问）→ 灰（在递归栈中）→ 黑（已完成）；灰到灰的边 = 环
- **拓扑排序**：DFS 后序的逆序（见第 3 节）
- 进阶：割点、桥、强连通分量（Tarjan 系，都建立在 DFS 的时间戳上）

### 2.2 BFS：一圈一圈往外推

```
bfs(src):
    queue := [src]; visited[src] = true; dist[src] = 0
    for queue 非空:
        u := queue 出队
        for v in adj[u]:
            if !visited[v]:
                visited[v] = true          // 入队即敲定
                dist[v] = dist[u] + 1
                v 入队
```

正确性支点：**入队顺序 = 跳数顺序，单调不减**。所以一个点首次被发现时，它的跳数已是最终答案——这就是"入队即敲定"敢用的理由。对照 Dijkstra：把"跳数"换成"总程"，"首次发现即终审"就不再成立（迟发现的路径可能更近），敲定必须推迟到出队。这是 BFS 与 Dijkstra 的本质分界。

内存形态：DFS 的栈深是图的**深度**，BFS 的队列宽是图的**宽度**，两者可能差一个量级（链 vs 星）。

应用：单位权最短路、层序遍历、多源 BFS（全部源点先入队，得到"每个点离最近源点的距离"）、状态空间搜索（把状态当节点，转移当边）。

### 2.3 多源 BFS：一次遍历，最近源距离

问题：给定 $k$ 个源点，求每个顶点到**最近**源点的跳数。朴素做法逐源跑 $k$ 遍 BFS，得到 $k$ 张距离表，再**逐顶点**对齐取 min（注意：不是对每趟的总时长取 min）合成一张表，$O(k(V+E))$；多源 BFS 把它压成一遍 $O(V+E)$，与源点个数无关。

**做法只有一行**：把全部源点入队（$dist = 0$），循环体与单源 BFS 逐字相同。

**为什么对：超级源点归约**。想象加一个虚拟点 $S$，向每个源点连一条边。多源 BFS $\equiv$ 从 $S$ 跑单源 BFS（$S$ 占第 0 层，$k$ 个源同处第 1 层）。层序单调对所有源统一成立，"入队即敲定"原封不动继承——$dist[v] = \min_s dist_s[v]$ 不是巧合，是单源最短路在这棵虚拟树上的直接结论。4.2 节的出队单调律照样适用，一个证明服务全家。

两个实现要点（`algo/multibfs.go`）：

- **dist 兼任 visited**：$-1$ 哨兵表示未发现，首次赋值即终值——"发现 = 赋距离"一个动作完成，省掉单独的访问表
- **前驱树语义升级**：`paths[v]` 回溯到根，得到的是 v **最近的**那个源（`pathTo` 无需改动直接复用）

典型场景（共同模式："多个等价起点，只要最近/最快的那份答案"）：

| 场景 | 源点 | 问什么 |
|---|---|---|
| 网格扩散：腐烂橘子、火势/病毒蔓延 | 初始感染点 | 每格何时被波及 / 总时长 |
| 最近设施：基站/仓库/消防站 | 设施 | 每个用户离最近设施多远（paths 版还能答归哪个站管）|
| 01 矩阵（LC 542） | 所有 0 | 每个 1 到最近 0 的距离 |
| 网格 Voronoi | 势力中心 | 每格最先归属哪个源 → 按源划分领地 |
| 多出口逃生 | 所有出口 | 反向跑一遍，人人到最近出口的距离 |
| 状态空间搜索 | 多个等价初始状态 | 最少转移步数 |

**家族推广：多源 × 带权最短路**。超级源点归约不依赖 FIFO 这个取出规则，对第 0 节的候选池骨架整个成立——加一个虚拟点 $S$，以 **0 权边**连向所有源点，任何单源算法都能这样升级成多源：

| 单源算法 | 多源姿势 | 前提 | 产出 |
|---|---|---|---|
| BFS | 全部源 $dist=0$ 入队 | 权全 1 | 每点到最近源的跳数 |
| 0-1 BFS | 全部源 $dist=0$ 入双端队列 | 权 $\in\{0,1\}$ | 同上 |
| Dijkstra | 全部源 $dist=0$ 入堆 | 非负权（0 权边合法）| 每点到最近源的**加权**最短路 |
| Bellman-Ford | 全部源 $dist=0$，松弛 $V-1$ 轮 | 无负环 | 同上，负权也能算 |

合法性只需检查一处：Dijkstra 的正确性前提是"非负权"，虚拟边权取 0 不破坏它——出堆单调性依旧，"首次出堆即定稿"原样继承。所以多源 Dijkstra 不是近似，是与单源同级的精确算法，复杂度仍 $O(E\log V)$，与源点个数无关（对照逐源跑 $k$ 遍 + $k$ 张表逐点取 min 的 $O(kE\log V)$）。

加权版的问题形态（注意：以下是"最近设施"类问题的**数学结构**，不等于生产系统的实现方式）：

- 导航"附近最近的充电桩/加油站/急诊"：求用户位置到最近设施的路网距离
- 电商履约：订单到"最便宜仓 + 路线"的组合
- 网络接入：请求到接入点的最低延迟

**生产系统的真实做法**（避免误以为它们在跑多源 Dijkstra）：

- 地图"附近"搜索：geohash/S2/H3 空间索引先筛出 K 个候选（球面距离近似），再从**用户单源**跑 A* 验证真实路网距离——设施集和过滤条件（充电桩类型、价格）动态变化，预计算距离场不划算
- CDN/就近接入：Anycast 在 BGP 层分流 + 实时 RTT 探测，根本不走图算法
- 多仓履约：业务规则（库存、成本、时效承诺）主导，距离部分用距离矩阵服务

多源 Dijkstra 的真实适用前提：**设施集与路网都稳定、查询量巨大、且需要全量距离场**（离线路网分析、交通/网络仿真中的到达时间场、游戏内静态地图的预计算导航网格）——一次预处理换 $Q$ 次 $O(1)$ 查表才回本。

**场景澄清（多源 ≠ 物理并行前往）**：单次查询（一个用户问一次）用单源 Dijkstra 从用户出发、到各设施取 min 即可，不必多源。多源的定位是**预计算距离场**：设施当源跑一次，得到每个点到最近设施的距离（paths 还能答"归哪个设施"），此后任意查询 $O(1)$ 查表——$Q$ 次查询从 $Q \cdot O(E\log V)$ 降为一次预处理加 $Q \cdot O(1)$。两种视角逐点等价（无向图中用户单源的 $\min_s$ = 设施多源场在用户处的值；有向图经反边对称）。与腐烂橘子对照：那边多源是**模拟物理并行**（答案 $\max_v\min_s$），这边是**构建查询索引**（答案逐点 $\min_s$）——同为多源，目的不同，聚合也不同。

**对称技巧：多目标 → 多源**。有向图上"每个点到最近**目标**"（全楼的人到最近出口、所有司机到最近收费站）等价于**反转全部边后**把目标当源跑多源——一次遍历代替逐点单源。无向图边双向，直接就是多源问题。

（代码位：`MultiSourceDijkstra` 待落地，骨架与 `algo/multibfs.go` 同构，仅把队列换优先队列、种子阶段全部源以 $dist=0$ 入堆；测试 oracle 可用多源 Bellman-Ford 交叉验证。）

**聚合陷阱（腐烂橘子系问题的经典坑）**：多源 BFS 给出的是 $dist[v] = \min_s dist_s(v)$，题目答案还需再包一层量词——总时长 $= \max_v dist[v]$，即 $\max_v \min_s$。注意量词顺序：$\min_s \max_v dist_s(v)$（"选一个源独自包场，取最快者"）是串行语义，答案会偏大。例：$[[2,1,1],[0,1,1],[0,1,2]]$，双源并行答案 $\max_v\min_s = 2$，而 $\min_s\max_v = 3$。min/max 的包裹顺序就是并行/串行的语义开关。

测试方法论（`algo/multibfs_test.go`）：oracle 用逐源单源 BFS 取 min（零共享逻辑）；另断言不变量 $\mathrm{pathLen}(paths, v) = dist[v]$——前驱树回溯长必须等于距离，比单点比对更能兜住"最近源归属"边界。

## 3. 有向图的结构：环检测与拓扑排序

DAG（有向无环图）是大量问题可解的前提：依赖解析、DP 求解序、增量计算。**拓扑排序 = 把 DAG 的点排成线性序，所有边从前往后。**

### 3.1 Kahn 算法（入度法）

```
把所有入度 0 的点入队
for 队列非空:
    u := 出队, 输出 u
    for v in adj[u]: 若 --indeg[v] == 0 则 v 入队
若输出点数 < V → 有环
```

环检测是免费的副产品：环上的点入度永远削不到 0。Go 标准库 `go/types/initorder.go` 用它的加权变体决定包初始化顺序（优先队列按剩余依赖数排序，`heap.Fix` 维护），是"拓扑序 + 优先级"结合的范例。

### 3.2 DFS 后序法

点的完成时刻（黑化时刻）取逆序即拓扑序。直觉：没有出边通往"更晚完成"的点，所以后序逆序里所有边都指向前面的点。

两法都是 $O(V+E)$。Kahn 直观且天然给环检测；DFS 法复用现有遍历代码。

## 4. 最短路：从特例到一般

### 4.1 问题分类

| 维度 | 取值 |
|---|---|
| 目标范围 | 单源单目标 / 单源全目标 / 全对全 |
| 边权 | 无权（=全 1）/ 0-1 / 非负 / 可负 / 可负环 |

### 4.2 统一视角：出队单调性

整个最短路家族的命脉是一句话：

> **轮到谁出队时，谁的距离已不可能再变小。**

不同边权条件下，用什么结构维持这句话：

| 边权情况 | 保单调的结构 | 算法 | 复杂度 |
|---|---|---|---|
| 全为 1 | 普通队列（FIFO 天然按跳数有序） | BFS | $O(V+E)$ |
| 只有 0 和 1 | 双端队列（权 0 头插、权 1 尾插） | 0-1 BFS | $O(V+E)$ |
| 任意非负 | 优先队列（按累计距离） | Dijkstra | $O(E \log V)$ |
| 小整数权 | 桶队列 | Dial | $O(E + VW)$ |
| 有负权 | **无解**——单调性在信息层面破产 | Bellman-Ford / SPFA | $O(VE)$ |

负权为什么无解：一条负边能让"处理得更晚的点"反而"离源更近"，而任何出队规则都无法预知还没扫描的边里藏着多深的负数。

### 4.3 Dijkstra：非负权单源最短路

**它不是遍历，是发榜**：每轮从未揭晓者中挑出离 src 最近的，宣布其最终距离。循环下标 $i$ 的真名是"名次"，$V$ 个点 $V$ 个名次，所以循环 $V$ 次。

贪心断言（敲定为什么安全）：设本轮敲定 $u$，值 $d$。任何可能更短的路径必先离开已敲定区域，经过某个未敲定点 $y$；argmin 刚确认 $\mathrm{dist}[y] \ge d$，而剩余路径边权非负、只增不减，故该路径 $\ge d$。翻案者必须在入口处先交 $\ge d$ 的入场费。

由这条单调律派生出三个实现事实（`algo/dijkstra.go` 可对照）：

1. **松弛循环不需要查 `done`**。已敲定的 $e.To$ 比 $u$ 更早被选中，$\mathrm{dist}[e.To] \le \mathrm{dist}[u]$，于是 $nd = \mathrm{dist}[u] + w \ge \mathrm{dist}[e.To]$，更新条件对定稿点恒假——保护是涌现的，不是代码强加的。
2. **`done` 的真身是"出堆"**。堆版没有 `done`，因为 `Pop` 物理离堆即除名；朴素版原地扫数组，节点不挪窝，只能开布尔账本。
3. **堆条目是快照，`dist` 数组是活账本**。惰性删除下同一节点可有多份历史条目，弹出时与数组对账，落后即丢弃。

两个实现、一个联动：

- 朴素版（argmin 扫描）$O(V^2)$：结构上就是一趟选择排序，键是距离（且键会被松弛改小，但已上榜的键永不改）。**稠密图（$E \approx V^2$）下渐近最优、常数最小**。
- 堆版 $O(E \log V)$：稀疏图主力。二叉堆做不到高效降键（decrease-key），所以用"重复入队 + 陈旧跳过"模拟。
- 表示法与取最小结构**联动**：邻接矩阵扫邻居是 $O(V)$，配堆总复杂度仍是 $O(V^2)$，堆的钱白花；矩阵天然配朴素版。

负权反例（经典版给出错解的现场）：边 $0 \to 1\,(2)$、$0 \to 2\,(3)$、$2 \to 1\,(-2)$。真值 $\mathrm{dist}[1] = 1$；Dijkstra 先敲定 $1 = 2$，后发现的绕行无法翻案，答案错成 2。病根即"剩余路径只增不减"被负权打破。

### 4.4 Bellman-Ford 与 SPFA：标号修正

两大家族的分野：

- **标号设定**（label-setting，Dijkstra 家）：出队那一刻标号定死，每点只处理一次。快，但需要单调出队序，负权下无解。
- **标号修正**（label-correcting，BF 家）：标号永远暂定，反复修正到收敛。慢，但任何边权都能算（无负环）。

Bellman-Ford 本体：把**全部边**整批松弛 $V-1$ 轮，$O(VE)$。不变量：第 $k$ 轮结束后，所有"最多 $k$ 条边"的最短路已正确。第 $V$ 轮还能改进 → 存在负环（最短路不存在）。

SPFA（队列版 BF）：只松弛"上轮被改进过的点的出边"——改进了谁，谁才有资格传播。用 FIFO 队列 + 允许重入队，正确性靠收敛（队列空 = 无改进可做）。最坏仍是 $O(VE)$，链状反例数据能把它打穿。附赠能力：负权可算，负环可检。

### 4.5 Floyd-Warshall：全对全

三重循环的 DP，**必须**用邻接矩阵（所以它和矩阵表示天然绑定）：

```
for k in 0..V-1:              // 允许经过中转 k
    for i in 0..V-1:
        for j in 0..V-1:
            d[i][j] = min(d[i][j], d[i][k] + d[k][j])
```

直觉：$d_k[i][j]$ = 只允许经过前 $k$ 个点中转的最短路，$k$ 外层滚动。$O(V^3)$ 时间、$O(V^2)$ 空间。顺带：查 $d[i][i] < 0$ 检测负环；改 `min` 为 `or` 求传递闭包。$V$ 上千就别想了，但中小规模的稠密图全对全问题它是代码量最小的答案。

## 5. 最小生成树（MST）

无向连通图里选 $V-1$ 条边连通全部点、总权最小。理论基石是**切分定理**：任意把点分成两堆，横跨两堆的边里权值最小的那条必在某个 MST 里——两个算法都是它的不同执行方式。

### 5.1 Kruskal：全局排序 + 并查集

边按权排序，从小到大尝试加入；两端点已连通（并查集查询）就跳过。$O(E \log E)$，排序主导。并查集（路径压缩 + 按秩合并）单次操作近 $O(1)$。**只认边不认点**，天然适合边列表表示，也天然适合"按边流式到达"的场景。

### 5.2 Prim：Dijkstra 的孪生兄弟

骨架与 Dijkstra 完全同构（优先队列 + 敲定 + 更新），唯一区别是堆里的 key：

| | Dijkstra | Prim |
|---|---|---|
| key 含义 | src 到该点的路径**总长** | 该点到"已生成树"的**单条边权** |
| 松弛比较 | 新总长 < 旧总长 | 新边权 < 旧边权 |
| 生成物 | 最短路树 | 最小生成树 |

一个攒"从根出发的路程"，一个攒"接入树最便宜的一根线"。配堆 $O(E \log V)$，适合稠密图（配朴素扫描 $O(V^2)$）。

MST 的典型延伸：单链接聚类、网络布线、TSP 的 2-近似算法第一步。

## 6. 进阶路标（不展开，给方向）

- **强连通分量**（有向图里互相可达的极大点集）：Tarjan 一次 DFS 完成，核心是栈 + 低链接值。缩点后 DAG 化是处理有向图的通用预处理。
- **2-SAT**：布尔可满足性的图化归，缩点 + 拓扑序取解。
- **网络流**：Ford-Fulkerson 增广路框架 → Edmonds-Karp（BFS 找增广路，$O(VE^2)$）→ Dinic（分层图，$O(V^2E)$）。
- **二分图匹配**：匈牙利算法（增广路），Hopcroft-Karp（$O(E\sqrt V)$）。
- **A\***：Dijkstra + 启发函数 $h(v)$（到目标的估价）。只要 $h$ 不超过真实剩余距离（可采纳性），敲定顺序仍安全，搜索被显著导向目标。$h \equiv 0$ 时退化为 Dijkstra。
- **DAG 上的 DP**：拓扑序即求解序，最短路/最长路/计数都是一遍线性扫描——DAG 是"最友好的一类图"。

### 测试方法论

本仓库图算法测试沉淀的模式：**独立 oracle + 固定种子随机 + 核心不变量断言**。

- oracle 必须与被测代码零共享逻辑（Dijkstra 的对照是朴素 Bellman-Ford，不是另一个 Dijkstra）
- 随机数用固定种子（`rand.New(rand.NewPCG(...))`），失败可复现
- 构造用例时主动覆盖特定分支（如陈旧条目跳过、不可达提前收工），随机测试未必命中
- 断言不变量而非单点（"堆弹出序 = 排序序"比"这个输入输出这个数组"更能兜住边界）
