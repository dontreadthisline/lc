# 家族 14：堆 —— 专题讲解

> 本族已有专门材料：`docs/leetcode-heap-list.md`（六大角色 + 刷题顺序）、`docs/heap-properties-proof.md`（堆性质证明）、`algo/genericheap.go`（通用实现）。本文是方法论层的浓缩与引用。

## 0. 速查卡（复习用）

- **信号**：Top-K / 前K个最频繁 / 流式取中位数 / 动态极值 / 合并 K 路有序流 / 调度按序取
- **原语**：小顶堆取最小、大顶堆取最大、**反向堆**（求第 K 大维护 size=K 的小顶堆）、双堆中位数
- **锚点**：要的是极值还是第 K 个 → 流式还是静态（静态先排序）→ 反向堆的方向对吗 → 进出堆的均摊账
- **失效**：静态一次性 Top-K 用快选 O(n)（`docs/quickselect-partition-proof.md`）；要"任意中位数查询+删除"需要双平衡树/有序集

## 1. 识别与反识别

**正信号**："第 K 大 / 前 K 个 / 流中位数 / 合并 K 个链表 / 每次取最小拼结果"。

**负样本对照**：

| 对比 | 分野 |
|---|---|
| 215 第K大 vs 347 前K高频 | 215 数值本身做键；347 先哈希计数（家族 1）再堆——**349/347 型是"预处理 + 堆"的拼装** |
| 堆 vs 快速选择 | 静态一次查询 → 快选平均 O(n)；**流式/反复取** → 堆 O(log n) 每次——数据到达方式决定结构 |
| 堆 vs 排序 | 全量排序 O(n log n) 拿全部序；只要 K 个 → 维护 K 大小的堆 O(n log K)，K ≪ n 时完胜 |

## 2. 入门讲解

堆回答一个问题：**反复地、动态地取当前最值**。排序一次付清全部序（O(n log n)），堆按需逐次取（每次 O(log n)）——付账模式不同，选型就不同。

**反向堆（215 的心法）**：求第 K 大，为什么维护的是**小**顶堆？堆里始终装"目前最大的 K 个"，堆顶是这 K 个里**最小**的——新来的数只要打败堆顶就能入伙。堆顶 = 第 K 大。**反着建堆是本族第一反直觉**：求大用小堆，求小用大堆。

**Top-K 完整流程（347）**：哈希计数 → 以计数为键建 size=K 小顶堆 → 扫描进出 → 堆里剩下的即答案。两族原语的拼装。

**双堆中位数（295，数据流）**：大顶堆装左半（较小的一半），小顶堆装右半，两堆顶夹着中位数。插入新数 → 选一侧入堆 → 平衡两堆大小差 ≤ 1 → 中位数从两堆顶读出。**两个堆互为镜像，中位数在夹缝里**。

**合并 K 链表（23）**：K 个当前头节点入小顶堆，每次弹出最小接到结果链，再把它的新后继入堆——**K 路归并 = 堆当调度器**。

## 3. 原语库

| 原语 | 签名 | 前置条件 | 复杂度 |
|---|---|---|---|
| 取最值 | push/pop，堆顶即极值 | 全序可比 | O(log n)/次 |
| 反向 Top-K | size=K 的反向堆，败者淘汰 | K ≪ n 或流式 | O(n log K) |
| 双堆中位数 | 大顶堆(左半) + 小顶堆(右半)，大小差 ≤1 | 插入流 | 插入 O(log n) 查询 O(1) |
| K 路归并 | K 个游标入堆，弹出即接续 | 各路有序 | O(N log K) |
| 延迟删除/懒堆 | 入堆时带版本，弹出时验尸 | 有删除操作的流 | 均摊 O(log n) |

## 5. 数学形式化

**堆性质与 sift 的正确性**：见 `docs/heap-properties-proof.md`（完全二叉树 + 父子序，siftUp/siftDown 保持性质的归纳证明）。

**反向 Top-K 不变量**。

- **命题**：扫描完 n 个数后，size=K 小顶堆恰含全局最大的 K 个
- **证明**：不变量——任意时刻堆内 = 已见数的最大 K 个。新数 x：x > 堆顶 ⟹ 堆顶是已见最大 K 个之外的最大者，换入 x 保持不变量；x ≤ 堆顶 ⟹ x 连"已见第 K 大"都不是，弃之无损 ∎
- **假设**：堆以"门槛"语义维护；K 固定
- **反例**：求第 K 大建大顶堆——堆顶语义是"当前最大"，与"第 K 大门槛"错位

**双堆中位数定理**。

- **命题**：两堆满足"左堆全体 ≤ 右堆全体、大小差 ≤ 1"时，中位数可从两堆顶 O(1) 读出
- **证明**：两堆并集有序化后，中位位置落在堆顶夹缝——大小差 0 取均值，差 1 取长侧堆顶 ∎
- **假设**：插入路径保证"先过对侧堆顶再入堆"（新数先入对侧再弹出最大/最小转正——保证跨堆有序性不被破坏）

**均摊账本**：懒删除堆的弹出均摊 O(log n)——每个元素入堆一次至多出堆一次，验尸失败的弹出由后续真弹出支付（家族 5 单调栈的摊还论证同构）。
